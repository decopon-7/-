# 初期コンテンツカレンダー(第1弾 全20本)

チャンネル戦略書([channel-strategy.md](./channel-strategy.md))で定めた6シリーズに沿って、立ち上げ最初の20本を計画する。
各動画には「発達的ねらい」を必ず設定し、概要欄にも同内容を記載すること。

凡例: **形式** = 長尺(3〜8分) / ショート(15〜60秒)

## 運用ルール

- 各動画の概要欄冒頭2行に「この動画のねらい」を必ず記載する(SEO + 保護者への信頼訴求)
- ショートは対応する長尺本編があれば概要欄・終端カードで誘導する
- 週次で再生維持率・クリック率(CTR)・シェア数をレビューし、伸びたシリーズ・タイトルパターンを次月の企画に反映する(詳細は [channel-strategy.md](./channel-strategy.md) §7参照)
