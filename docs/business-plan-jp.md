# 事業計画(日本版)

日本語コンテンツのサイトを資産として積み上げ、国内ASPのアフィリエイト報酬(円建て)を得る事業。海外版は [business-plan.md](business-plan.md) を参照。

## 1. 現実的な前提
- 円建てのため、ドル建て・円安ヘッジの効果はない。
- 成果まで通常6〜12か月。最初の半年は収益ゼロも普通。
- 日本は大手メディアが上位を占めやすく、個人サイトには競合が強い。ニッチ選定が成否を分ける。
- 収益額は保証できない。以下の数字は仮定の試算。

## 2. ニッチ選定基準
1. 成約単価が高い、または継続課金(通信回線、VOD、転職、脱毛、SaaS、ふるさと納税など)
2. 検索意図が購入に近い(「〇〇 比較」「〇〇 おすすめ」「〇〇 口コミ」)
3. 自分で体験して一次情報を出せる
4. 規制が重い領域(医療・健康効果の訴求、金融商品)は初期は避ける

## 3. 収益モデル(試算例・仮定)
| 項目 | 仮定 |
|---|---|
| 公開記事数 | 100本/サイト |
| 月間オーガニック訪問 | 30,000 |
| クリック率 | 3% → 900クリック |
| 成約率 | 2% → 18件 |
| 平均報酬 | ¥4,000 |
| 月間収益 | 約¥72,000/サイト |

3サイトで約¥216,000/月。到達に12〜24か月かかり、未達も十分あり得る。

## 4. 資金計画(初年度・概算)
| 項目 | 金額目安 |
|---|---|
| 法人設立(合同会社) | 約6〜10万円 |
| ドメイン・サーバー・テーマ・ツール | 約5〜15万円/年 |
| 記事制作(外注/AI下書き+編集) | 約20〜60万円 |
| 税理士 | 約15〜30万円/年 |
| 合計 | 約50〜120万円 |

法人化せず個人事業(開業届+青色申告)で始め、収益が安定してから法人化する方が低コストな場合もある。税理士に相談する。

## 5. マイルストーン
| 時期 | 目標 |
|---|---|
| 0-1か月 | 法人 or 開業届、ASP登録、ニッチ決定、サイト公開 |
| 2-6か月 | 50〜100記事公開、主要広告主の提携承認 |
| 6-12か月 | 順位・成約データで記事改善、2サイト目着手 |
| 12か月〜 | 外注体制と月次保守で半自動運用 |

## 6. 運営(国内版の要点)
- **ASP**: A8.net、もしもアフィリエイト、afb、アクセストレード、バリューコマース、Amazonアソシエイト、楽天アフィリエイトを併用。同一広告主でも報酬が異なるため比較する。
- **サイト**: WordPress+高速サーバー。必須ページは運営者情報、プライバシーポリシー、広告掲載の明示。
- **記事**: 比較ハブ → 個別レビュー → 悩み解決系の順に作る。実際に使った写真・所感・料金・メリット/デメリット・最終更新日を必須にする。
- **外注**: クラウドソーシングで1記事数千円〜。編集チェックリストで品質を担保。
- **月次保守(2〜4時間目安)**: 順位低下記事の確認、リンクと料金の確認、広告主の提携終了・規約変更の確認、新規記事公開。

## 7. 法規制・コンプライアンス
| 項目 | 内容 |
|---|---|
| ステマ規制(景表法) | 広告であることを明示する。記事冒頭付近に「広告を含みます」等の表示 |
| 景表法 | 優良誤認・有利誤認となる表現を避ける(最安、No.1等は根拠と出典が必要) |
| 薬機法 | 化粧品・健康食品で効能効果を断定しない |
| 金融商品取引法等 | 金融・投資系は表現と提携条件に注意 |
| 著作権・画像 | 無断転載禁止。画像は自前撮影か許諾済みのみ |
| ASP規約 | 広告主ごとの禁止事項(ブランド名リスティング広告、自己アフィリエイト等) |
| 個人情報 | プライバシーポリシー、アクセス解析・Cookieの記載 |

## 8. 税務
- 個人事業:雑所得か事業所得かの判断、青色申告(65万円控除)を検討
- 法人:設立届、青色申告承認申請書は設立から3か月以内
- 消費税・インボイス登録の要否は売上規模と取引先で変わる。ASPからの支払通知書の扱いも含め税理士に確認
- 海外版と違い、外貨・源泉徴収・W-8BEN-Eの論点は基本的にない

## 9. リスクと対策
| リスク | 対策 |
|---|---|
| Googleアップデートで順位急落 | 複数サイト、SNS・メルマガなど流入源の分散 |
| 広告主の提携終了・報酬減 | 1記事で複数広告主を比較掲載、代替を用意 |
| 規約違反による提携解除 | 広告表示と表現ルールをチェックリスト化 |
| 競合大手との差 | 一次情報(実体験・独自調査)で差別化 |
| 円建て収益のみ | 英語版を並行し、収益通貨を分散(海外版計画を参照) |

## 10. 判断ルール
- 6か月経っても主要記事が表示されない → ニッチ・品質を見直す
- 12か月で月¥10,000未満 → 追加投資を止め、別ニッチへ
- 1広告主への収益依存が50%超 → 代替広告主の記事を増やす
