# 運営プレイブック

## 立ち上げ(0〜3か月)
1. **ニッチ決定**: キーワードツール(Ahrefs/Semrush/無料ならGoogle Keyword Planner)で、購入意図の強いキーワードを50〜100個リストアップ。
2. **サイト構築**: WordPress(軽量テーマ)+ 高速ホスティング + Cloudflare。必須ページ:About、Contact、Privacy、Affiliate Disclosure。
3. **コンテンツ設計**: "Best X for Y" の比較ハブ記事 → 個別レビュー → "X vs Y" → ハウツーの順に作る。
4. **品質基準**: 実際に使った所見、スクリーンショット、料金表、長所短所、最終更新日を必ず入れる。AIは下書きに限定し、人が事実確認・編集する。
5. **アフィリエイト申請**: サイト公開後、記事が10〜20本ある状態で申請する(承認率が上がる)。

## 半自動化の仕組み
| 業務 | 自動化・外注 |
|---|---|
| 記事執筆 | 海外ライターへ外注(1,000語$30〜$80)+ 編集チェックリスト |
| 順位・流入監視 | Google Search Console + Looker Studio の週次レポート |
| リンク切れ・プログラム終了検知 | 月次クローラー(Screaming Frog 等) |
| 記事の更新 | 6か月ごとに料金・機能を再確認する更新カレンダー |
| 収益集計 | 各ネットワークの月次明細を1シートに集約 |

## 月次保守チェックリスト(目安2〜4時間)
- [ ] Search Consoleで順位が20%以上落ちた記事を確認
- [ ] 収益上位10記事のリンクと料金表を確認
- [ ] 報酬の入金と、各プログラムの規約変更メールを確認
- [ ] 外注記事の納品・公開(月2〜4本)
- [ ] 為替レートを確認し、円転の要否を判断

## 判断ルール
- 6か月経っても主要記事がインデックス・表示されない → ニッチ/品質を見直す
- 12か月で月$100未満 → そのサイトへの追加投資を止め、別ニッチへ
- 1社への収益依存が50%超 → 代替プログラムの記事を増やす
