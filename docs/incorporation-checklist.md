# 会社設立・口座・税務チェックリスト

※一般的な情報です。実行前に税理士・司法書士に確認してください。

## 1. 法人形態
- **合同会社(推奨)**: 設立費用が安い(登録免許税6万円〜)。小規模事業に十分。
- 株式会社: 信用力は高いが、設立費用が約20万円〜。

## 2. 設立手順
- [ ] 商号・事業目的を決める(目的例:「ウェブサイトの企画・運営」「広告・アフィリエイト事業」「コンテンツ制作」「前各号に付帯する一切の業務」)
- [ ] 本店所在地を決める(自宅 or バーチャルオフィス。賃貸契約で事業利用可か確認)
- [ ] 定款作成(電子定款なら印紙代4万円が不要)
- [ ] 資本金の払込(1円〜可だが、数十万円あると信用面で有利)
- [ ] 法務局で設立登記
- [ ] 税務署・都道府県・市区町村へ設立届出(法人設立届、青色申告承認申請書は設立から3か月以内)
- [ ] 社会保険の加入手続き(役員報酬を出す場合)

## 3. 口座(ドル受取)
- [ ] 法人銀行口座(国内)
- [ ] 外貨受取:Wise Business / Payoneer / PayPal Business などの法人口座
- [ ] アフィリエイト各社に受取方法を登録(ACH、PayPal、Wise、Payoneer)
- [ ] 米国向け税務書類 **W-8BEN-E**(法人)を各プログラムに提出

## 4. 税務の論点(税理士に確認)
- 国外の事業者から受ける役務提供の報酬は、消費税の課税区分が論点になる
- 為替差損益の処理(受取時レート、期末評価)
- インボイス登録の要否(取引先が海外中心なら影響は限定的なことが多い)
- 経費計上の範囲(ツール、外注費、ドメイン、通信費)
- 米国源泉徴収の有無(W-8BEN-Eと租税条約の適用)

## 5. 法令・規約
- 米国FTC:アフィリエイト関係の明示が必須(各記事の冒頭付近)
- 日本の景表法・ステマ規制:日本向けコンテンツを作る場合に適用
- 各プログラムの規約(商標入札禁止、クッキー規定、禁止コンテンツ)を必ず確認
- プライバシーポリシー・Cookie同意(GDPR/CCPA)を設置
