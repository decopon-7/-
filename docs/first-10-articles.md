# サブテーマと最初の10記事

## サブテーマ
**「副業を始める会社員の開業〜確定申告を、会計ソフトで楽にする」**

- 想定読者: 副業収入が出始めた、または出る予定の会社員(開業届・確定申告・会計ソフト選びで迷っている人)
- 収益導線: 会計ソフト(freee、マネーフォワード、弥生など)、請求書ツール、レンタルサーバー。提携の有無と報酬は ASP で要確認
- 選定理由: 「会計ソフト 比較」「副業 確定申告」は成約に近い検索で、無料体験で一次情報(画面・手順)を出せる。規制は軽い
- 差別化: 「会社員×副業」に限定し、住民税・会社への影響・少額から始める手順まで扱う

## 公開順の考え方
1. **#1〜3 を先に公開**: 検索ボリュームが大きい入口記事で、サイトの専門性を示す
2. **#4 比較ハブは早めに骨格を作り**、#5〜6 が公開されるたびに追記する
3. **#7〜10 で関連語を拡張**し、全記事から #4 へ内部リンクを集める

## 各記事で必ず入れるもの
- 冒頭付近に広告表示(「本記事は広告を含みます」等)
- 最終更新日と、制度の根拠(国税庁などの一次情報へのリンク)
- 実際に操作した画面キャプチャ(#4〜6、#8〜9)。自前撮影のみ使用
- 料金・機能は公開時点の情報であることの注記と、公式ページへのリンク

## 注意点
- **税理士法**: 一般的な制度解説にとどめ、個別の税務判断・節税の断定はしない。「詳しくは税務署・税理士へ」と案内する
- **制度の変動**: 20万円ルール、住民税、インボイス、電子帳簿保存法は改正があり得る。タイトルの年号は更新ごとに見直す
- **「会社にバレない」表現**: 就業規則違反を助長する訴求は避け、仕組みの説明にとどめる(#10)
- **効果の断定禁止**: 「確定申告が必ず楽になる」「最安」等は根拠を示せる場合のみ
