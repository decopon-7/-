# Steam 販売までのロードマップ

いまは「遊べる最小のプロトタイプ」の段階です。ここから製品にするまでの流れをまとめます。
金額や審査日数は 2026 年時点の一般的な目安なので、実際に手続きするときは Steamworks の公式ドキュメントで確認してください。

## フェーズ1：ゲームを面白くする（〜2か月）

- [x] 皮むきの基本操作（3D・ドラッグでむく・回す）
- [x] 1日のノルマと時間制限、給金
- [x] アップグレード（ピーラー / 回転台 / 皮むき機 / 契約）
- [x] セーブ、日本語・英語切り替え
- [ ] **効果音**（むく音「シャリッ」、鍋に落ちる音、レジ音）と BGM ← 手ざわりに一番効く
- [ ] 芋の「芽」をくり抜く操作（芽を残すと減点など）
- [ ] 芋の種類（小さい・細長い・泥つき・腐りかけ＝むかずに捨てる判断）
- [ ] 自動化の段階を増やす（ベルトコンベア → 洗浄機 → 全自動ライン）
- [ ] 前線からの手紙・上官の無茶な注文など、日ごとのイベントで物語をつける
- [ ] 友人数人に遊んでもらい、「何分で飽きたか」「どこで気持ちよかったか」を聞く

## フェーズ2：見た目と中身を製品レベルにする（〜4か月）

- [ ] モデルを作り直す（Blender で芋・ピーラー・調理場。無料素材を使うならライセンスを必ず確認）
- [ ] 設定画面（音量、解像度、フルスクリーン、マウス感度）
- [ ] コントローラー対応（Steam Deck で遊べると販売上有利）
- [ ] チュートリアル
- [ ] 実績（Steam 実績に流用する）

## フェーズ3：Steam の準備（発売の 3〜6 か月前から）

1. **Steamworks に登録**：https://partner.steamgames.com/
   - 本人確認・銀行口座・税務情報（日本在住なら W-8BEN で米国源泉徴収を減免）を登録
   - アプリ1本ごとに **Steam Direct 手数料 100 米ドル**（売上が一定額を超えると返金）
2. **ストアページを作る**
   - カプセル画像（複数サイズ）、スクリーンショット 5 枚以上、トレーラー動画
   - ストアページ公開後、審査を経て「近日登場」で公開 → **ウィッシュリストを集める**のが最重要
3. **Steam Next Fest** に体験版で参加（ウィッシュリストが大きく伸びる定番ルート）
4. **Steamworks SDK と連携**
   - Godot 用には [GodotSteam](https://godotsteam.com/) を使う（実績・クラウドセーブ・オーバーレイ）
   - 開発中は `steam_appid.txt` を置いて動作確認（`.gitignore` 済み）
5. **ビルドとアップロード**
   - Godot の「エクスポート」で Windows（必須）/ Linux（Steam Deck 向け）/ macOS 用に書き出す
   - 書き出しには Godot の「エクスポートテンプレート」を事前にダウンロードする
   - SteamPipe（`steamcmd` の `run_app_build`）でアップロード
6. **審査**：ストアページとビルドはそれぞれ Valve の審査あり（数営業日）。
   発売ボタンを押せるのは「近日登場」ページ公開から 2 週間以上経ってから。

## 価格とお金の目安

- 同ジャンルの小規模シミュレーションは 500〜1,500 円程度が多い
- Steam の手数料は売上の 30%（売上が大きくなると段階的に下がる）
- 使っているものの費用：Godot（無料・MIT）、Noto Sans JP（無料・OFL）、GodotSteam（無料・MIT）
