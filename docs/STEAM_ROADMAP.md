# Steam 販売までのロードマップ

いまは「遊べる最小のプロトタイプ」の段階です。ここから製品にするまでの流れをまとめます。
金額や審査日数は 2026 年時点の一般的な目安なので、実際に手続きするときは Steamworks の公式ドキュメントで確認してください。

## 方向性のメモ

**スローライフ・落ち着いて遊べる路線。** 急かす要素（注文の締め切り、遅れると減点、など）は
今は入れない方針。追加する機能は「焦らせる」より「没頭できる・心地よい」を優先して選ぶ。
1日の時間制限は撤廃し、自分のペースで好きなだけ切って好きなときに終われるようにした。

ただし実際に遊んでみると、1日のノルマを完全に無くすと「ほぼ切らずに次の日へ」を繰り返して
ストーリー（日記・複数エンド）や実績をあっという間に消費できてしまい、逆に手応えが薄くなる
ことが分かった。そこで**時間制限はかけないまま、1日の最低量（200g）**だけを設けた。
急かす・失敗させる要素ではなく、「今日はここまで」で終業できるようになるまでの下限で、
達成できなかったからといって何かを失うことはない。

## 実況・配信で選ばれるための工夫（リサーチと反映）

「実況者に選ばれる／配信映えする／やってみたくなる／実況しやすい」ゲームの共通点を調べた結果、
大きく2系統に整理できた（詳しい検討は README.md にも要約あり）。

- **スペクタクル型**：`Among Us` などに代表される、最初の数十秒でつかむ速さ・クリップ映えする
  一瞬の見せ場を重視するタイプ。「30分チュートリアルは死」「30秒で対立に放り込め」という
  くらい速さが正義とされる
- **ASMR・癒やし型**：`PowerWash Simulator` などに代表される、満足感のある音・忙しくなさ・
  「見ているだけで落ち着く」ことを重視するタイプ。ストレス社会における「デジタルの瞑想」として
  ゆっくり伸びる

このゲームは既に「スローライフ・急かさない」を選んでいるため、①のスピード感を丸ごと
持ち込むのは方向性の矛盾になる。**②（ASMR・癒やし型）を軸に、①の「クリップになる一瞬」だけを
急かさない形で拝借する**、という結論にした。

- [x] 手応え（カメラの揺れ・スクワッシュ・きらめき・ヒットストップ）→ ②の心地よさと
      ①のクリップ映えを両立
- [x] 「幸運の玉ねぎ」（約4%の確率で金色に光り、報酬5倍）→ 実況者が思わず反応する
      「配信中に起きる嬉しい事件」を、強制力なしで用意
- [x] Hキーでの画面クリーン化（文字要素を消してきれいな画を撮れる）→ 実況・切り抜き向けの
      地味だが実用的な配慮
- [x] タイトル→開始まで数秒、チュートリアル待ちなし → 「最初の数十秒で退屈させない」に対応
      （①由来だが、単なる導線の速さなのでスローライフ路線とは矛盾しない）
- [ ] 検討したが保留：BGMに起伏をつけて「盛り上がる瞬間」を作る（テンポアップは以前に一度
      入れて → 急かす方針と衝突するため撤去済み。BGMの「曲調が変わる」程度なら再検討の余地あり）
- [ ] ストアページ・トレーラー側での配慮：実況者が概要を一目で説明できるよう、
      ジャンル名に「ASMR」「癒やし」を明記する。ネタバレなしの紹介文（日記の核心には触れない）
- [ ] 実況者向けの一言メモ（解像度・録画のコツなど）をストアページかREADMEに用意するか検討
- [ ] 「幸運の玉ねぎ」の頻度・報酬倍率は仮値（4% / ×5）。実際に遊んでもらって調整する

## フェーズ3：Steam の準備（発売の 3〜6 か月前から）

1. **Steamworks に登録**：https://partner.steamgames.com/
   - 本人確認・銀行口座・税務情報（日本在住なら W-8BEN で米国源泉徴収を減免）を登録
   - アプリ1本ごとに **Steam Direct 手数料 100 米ドル**（売上が一定額を超えると返金）
2. **ストアページを作る**
   - カプセル画像（複数サイズ）、スクリーンショット 5 枚以上、トレーラー動画
   - ストアページ公開後、審査を経て「近日登場」で公開 → **ウィッシュリストを集める**のが最重要
3. **Steam Next Fest** に体験版で参加（ウィッシュリストが大きく伸びる定番ルート）
4. **Steamworks SDK と連携**
   - Godot 用には [GodotSteam](https://godotsteam.com/) を使う（実績・クラウドセーブ・オーバーレイ）
   - 開発中は `steam_appid.txt` を置いて動作確認（`.gitignore` 済み）
5. **ビルドとアップロード**
   - Godot の「エクスポート」で Windows（必須）/ Linux（Steam Deck 向け）/ macOS 用に書き出す
   - 書き出しには Godot の「エクスポートテンプレート」を事前にダウンロードする
   - SteamPipe（`steamcmd` の `run_app_build`）でアップロード
6. **審査**：ストアページとビルドはそれぞれ Valve の審査あり（数営業日）。
   発売ボタンを押せるのは「近日登場」ページ公開から 2 週間以上経ってから。
