# サムネイル計画(初期20本 カット出し)

[content-calendar.md](./content-calendar.md)の初期20本について、[channel-strategy.md](./channel-strategy.md) §5のサムネイルルール(「表情がはっきり分かるキャラクターの顔+短い訴求テキスト(3〜5文字)。シリーズごとに色帯を統一しブランド認知を作る」)に沿ってカットを出し、実際のサムネイル画像を`assets/thumbnails/`に生成した。

## ステータス

現バージョンは、確定ポーズ集([character-design.md §6](./character-design.md#6-追加ポーズ生成済み確定))にある5種類のポーズを使い回した**プレースホルダー版**。撮影・編集が具体化した段階で、動画の実際のハイライトシーンに差し替える。

**2026-09-18更新**: 立ち上げ初期は「たねちゃん」に集中する方針のため、No.10・19(みどり先生・ほいくしのワンポイント)のサムネイルは保留対象。画像は参考として残すが、次の制作対象からは外す([channel-strategy.md](./channel-strategy.md) §4参照)。

**2026-09-19更新**: たねちゃん担当19本の台本([scripts/](../scripts/))が出そろったため、全ポーズ割り当てを台本の実際のクライマックスと突き合わせて再確認した。既存5ポーズ(wave/banzai/toothbrush/thinking/breathing)の範囲内では大きなズレはなし(下表参照)。一方で、てあらい(手を洗うしぐさ)・かぞえる(指折り)・なきまね(口を開けて鳴きまねする表情)・くらべっこ(両手を左右に広げる比較のしぐさ)・みずあそび(水しぶきを浴びるしぐさ)のように、専用ポーズがあればより動画内容に忠実になる項目を洗い出した。§「第2弾ポーズ生成プロンプト」に追加候補をまとめた。

## 第2弾ポーズ生成プロンプト(候補・未生成)

上記5パターンをGensparkで追加生成する場合のプロンプト案。[character-design.md §6](./character-design.md#6-追加ポーズ生成済み確定)の運用ルールに従い、確定デザイン画像を参照させて生成する。

```
添付画像のキャラクターと同じデザイン(種・双葉モチーフ、体色#FFD9A0、お腹#FFEFD1、
双葉#7DC9A7/#5FAE8C、ほっぺ#FFB6A0、足#EFB97F)を厳密に維持したまま、
以下5種類のポーズを1枚のシートに並べてください:
1. 両手で水をすくって手を洗う・あわ立てているポーズ
2. 片手の指を1本ずつ折りながら数えているポーズ
3. 両手を左右に大きく広げて「おおきい」を示しているポーズ
4. 水しぶきを浴びて楽しそうにしているポーズ(水滴が数滴飛んでいる程度で、過度な演出はしない)
5. 口を大きく開けて動物の鳴きまねをしているポーズ
輪郭線は最小限、鋭角なし、丸みのあるフォルムを維持。背景は無地の生成り色(#FFF9F2)。
```

生成でき次第、`assets/characters/poses/`に追加し、該当するサムネイル(No.1・6・14・15・16・20)とスクリプトの演出メモを差し替える。

## レイアウト仕様

- 解像度: 1280×720(YouTube標準)
- 左側: シリーズカラーの単色背景 + 太字テロップ(白文字+ダークブラウン#3A2E26のアウトライン、視認性優先)
- 右側: オフホワイト角丸パネル上にキャラクターポーズを配置
- 左下: シリーズ名の小さなピルバッジ
