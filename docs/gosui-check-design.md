# 午睡チェック 設計メモ（v0.2）

保育士用アプリの最初の機能。水遊びチェック表の「タップだけで入力が完結」「一覧で誰が該当か一目でわかる」を踏襲する。

## 画面

| タブ | できること |
|---|---|
| チェック | クラスを選び、子どもごとのカードで 午睡開始 → 体位タップ（仰／右／左／う）→ 起床。次の確認までの残り時間を表示し、近づくと黄、過ぎると赤で点滅。音と振動でも知らせる |
| 記録 | 確認間隔ごとの時間枠で、体位と記録者を一覧表にする。確認が抜けた枠は「未」。前の日の記録も見られる。印刷ボタンで紙に出せる（監査・保存用） |
| 設定 | 音のオンオフ、パスワード変更、ログアウト。管理者はクラスごとの確認間隔（＋／−）、子ども・職員の登録と停止、全端末ログアウト |

## 決めたこと

- **確認は1人ずつタップする。** 「全員まとめて確認」ボタンは、1人ずつ目で見る確認を省けてしまうため置かない（午睡開始だけはまとめて押せる）
- **うつぶせを押したら、仰向けに直したことを確認してから記録する。** 記録には「う→仰」と残る
- **記録者を必ず残す。** 記録者の初期値はログインした本人。共有タブレットでは画面上部で交代する
- 押し間違いは「1つ取り消す」で直前の1件だけ戻せる
- 起床後に再び寝た場合は「もう一度寝た」で、同じ日の2回目の午睡として記録する
- 午睡中は画面が消えないようにする（対応している端末のみ）
- オフラインでも開ける（PWA）

## 確認間隔の初期値について

園を作る時の初期値は 0歳5分・1〜2歳10分 にしている。これは広く使われている目安として入れた仮の値で、根拠の照会はまだ済んでいない。
**園のマニュアル・いわき市／福島県の指導内容を確認してから確定する。** 管理者が設定画面でクラスごとに1分単位で変えられる。

## データの保存

v0.2 からサーバー（Cloudflare D1）に保存する。表の定義とログイン・共有の仕組みは [server-design.md](server-design.md) を参照。
サーバーがない環境では「デモで試す」で、サンプルデータのみ端末の中で動かせる。

## 残っている制約

- 画面を閉じている間（スリープ・別アプリ表示中）は音が鳴らない
- 記録の保存期間・書き出し・バックアップの方針が未定
