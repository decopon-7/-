# 午睡チェック 設計メモ（試作 v0.1）

保育士用アプリの最初の機能。水遊びチェック表の「タップだけで入力が完結」「一覧で誰が該当か一目でわかる」を踏襲する。

## 画面

| タブ | できること |
|---|---|
| チェック | クラスを選び、子どもごとのカードで 午睡開始 → 体位タップ（仰／右／左／う）→ 起床。次の確認までの残り時間を表示し、近づくと黄、過ぎると赤で点滅。音と振動でも知らせる |
| 記録 | 確認間隔ごとの時間枠で、体位と記録者を一覧表にする。確認が抜けた枠は「未」。印刷ボタンで紙に出せる（監査・保存用） |
| 設定 | 年齢ごとの確認間隔（＋／−）、音のオンオフ、職員・子どもの登録、記録の消去 |

## 決めたこと

- **確認は1人ずつタップする。** 「全員まとめて確認」ボタンは、1人ずつ目で見る確認を省けてしまうため置かない（午睡開始だけはまとめて押せる）
- **うつぶせを押したら、仰向けに直したことを確認してから記録する。** 記録には「う→仰」と残る
- **記録者を必ず残す。** 未選択のまま体位を押すと、先に記録者を選ぶ画面が出る
- 押し間違いは「1つ取り消す」で直前の1件だけ戻せる
- 起床後に再び寝た場合は「もう一度寝た」で、同じ日の2回目の午睡として記録する
- 午睡中は画面が消えないようにする（対応している端末のみ）
- オフラインでも開ける（PWA）

## 確認間隔の初期値について

初期値は 0歳5分・1〜2歳10分 にしている。これは広く使われている目安として入れた仮の値で、根拠の照会はまだ済んでいない。
**園のマニュアル・いわき市／福島県の指導内容を確認してから確定する。** 設定画面で1分単位で変えられる。

## データの形（試作版は端末の localStorage）

```
設定  hoiku-nap-config-v1
  intervals: { 0: 5, 1: 10, 2: 10 }     年齢ごとの確認間隔（分）
  staff: ["…"], currentStaff: "…"
  classes: [{ id, name, age }]
  children: [{ id, name, classId }]

その日の記録  hoiku-nap-day-v1-YYYY-MM-DD
  naps: {
    [childId]: [                         1日に複数回寝た場合は複数件
      { start, end|null, checks: [{ t, posture, staff, fixed? }] }
    ]
  }
  posture: supine（仰向け）/ right / left / prone（うつぶせ）
```

本番化するときも、この形をそのままデータベースの表に移せるようにしている。

## 試作版の制約（本番前に必ず直すこと）

- ログイン・権限がない。**実在の園児の情報は入れない**（画面上部にも表示している）
- データは端末1台の中だけ。複数のタブレットで同じクラスを見ることはできない
- 端末のデータを消すと記録も消える
- 画面を閉じている間（スリープ・別アプリ表示中）は音が鳴らない
