# 午睡チェック 設計メモ（v0.3）

保育士用アプリの最初の機能。水遊びチェック表の「タップだけで入力が完結」「一覧で誰が該当か一目でわかる」を踏襲する。

## 画面

| タブ | できること |
|---|---|
| チェック | 午睡担当を2名選び（①②、タップで交代）、室温・湿度をタップで記録。クラスを選び、子どもごとのカードで 午睡開始、体位タップ（↑仰向け／→右向き／←左向き／↓うつぶせ）、起床。次の確認までの残り時間を表示し、近づくと黄、過ぎると赤で点滅。音と振動でも知らせる |
| 記録 | 確認間隔ごとの時間枠に、体位・**実際に確認した時刻**・記録者を入れた一覧表。前の確認から間隔を超えた確認は赤枠、確認が遅れていた枠は「未」。前の日の記録も見られる。印刷ボタンで紙に出せる（監査・保存用） |
| 設定 | 音のオンオフ。管理者モード（10分）で、職員（名前だけ）・子ども・クラス・登録している端末の管理 |

## 決めたこと

- **確認は1人ずつタップする。** 「全員まとめて確認」ボタンは、1人ずつ目で見る確認を省けてしまうため置かない（午睡開始だけはまとめて押せる）
- **体位は矢印で表す。** ↑仰向け／→右向き／←左向き／↓うつぶせ。左右の向きは園の紙の記録表と同じであることを依頼者が確認済み（2026-09-23）
- **うつぶせを押したら、仰向けに直したことを確認してから記録する。** 記録には「↓⇒↑」と残る（「→」は右向きと紛らわしいため「⇒」を使う）
- **記録者を必ず残す。** 午睡担当2名を ①② として選び、記録のたびにどちらが入力したかを残す。記録表の上に「記録者：① 佐藤 ② 鈴木」と出す（依頼者の決定）
- **室温・湿度も記録する**（依頼者の決定）。＋／−のタップだけで入力し、前回の値から始める。記録表の一番上の行に出す
- 押し間違いは「1つ取り消す」で直前の1件だけ戻せる
- 起床後に再び寝た場合は「もう一度寝た」で、同じ日の2回目の午睡として記録する
- 午睡中は画面が消えないようにする（対応している端末のみ）
- オフラインでも開ける（PWA）

## 確認間隔

**0歳は5分、それ以外は10分**（依頼者の決定・2026-09-23）。クラスの年齢から自動で決まり、設定では変えない。

## データの保存

v0.2 からサーバー（Cloudflare D1）に保存する。表の定義とログイン・共有の仕組みは [server-design.md](server-design.md) を参照。
サーバーがない環境では「デモで試す」で、サンプルデータのみ端末の中で動かせる。

## 記録表の約束（監査に出す前提）

- 時間枠の見出しではなく、**実際に確認した時刻**を必ず書く（枠の時刻で書くと、12:09 の確認が「12:05」に見えてしまう）
- 遅れの判断は表に出る「分」で行う（12:30→12:35 は遅れなし、12:30→12:36 は遅れ）
- 「未」は確認が本当に遅れていた時間にかかる枠だけ。入眠や確認の時刻と枠の区切りがずれているだけでは付けない
- 午睡を始めた時点のクラスと確認間隔を残す。あとでクラス替えや間隔の変更をしても、過去の表は変わらない
- 起床を押し忘れた日は、表を最後の確認までで止め「起床の記録なし」と出す。次の日の起床で前の日の午睡は閉じない

## 現場で確かめたいこと（未確定）

- 紙の午睡チェック表に、体位・室温・湿度のほかに **呼吸・顔色・睡眠の様子** の欄があるか（あればアプリにも必要）
- 確認は「子どもごとにタイマー」と「全員を決まった時刻に一巡」のどちらが実際の動きに近いか
- ①②の交代を押し忘れた時に困らないか（実際に使って確かめる）

## 残っている制約

- 画面を閉じている間（スリープ・別アプリ表示中）は音が鳴らない
- 記録の保存期間・書き出し・バックアップの方針が未定
