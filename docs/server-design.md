# サーバー・端末の登録・共有の設計（v0.3）

午睡チェックを「登録した園の端末だけで使え、園の複数のタブレットで同じ記録を見られる」形にする。

## 構成

```
タブレット・スマホ（PWA）
   │  https
Cloudflare Workers ── 画面のファイル（app/）を配信
   │                └ /api/* を処理（worker/）
Cloudflare D1（データベース）
```

- 画面のファイルそのものには園児の情報を含めない。園児・記録のデータは、登録した端末から `/api/*` でだけ取得できる
- 1つの仕組みで複数の園を扱えるよう、すべての表に `facility_id`（園）を持たせ、**登録した端末の園のデータしか読み書きできない**ようにサーバー側で絞る

## 端末の登録と「名前を選ぶだけ」

依頼者の決定（2026-09-23）：**職員は名前を選ぶだけ**で使う。職員一人ずつのパスワードは持たない。

- 管理者が「ログインID＋パスワード」で、タブレットを **園の端末として登録** する（最初の1回だけ）
  - 推測できない乱数の合言葉を端末の Cookie に保存（`HttpOnly`・`Secure`・`SameSite=Strict`）。データベースには変換した値だけを保存
  - 使っている端末は登録が続き、90日使わなかった端末は登録が切れる
- 職員は端末で **午睡担当を2名まで選ぶ**（①②）。記録のたびに、①②のどちらが入力したかが残る
- 監査用に、記録ごとに **記録者（選んだ名前）** と **入力した端末の名前** を残す
- 同じログインIDで15分間に5回失敗すると、しばらく登録・管理者モードに入れなくなる
- 書き込み（POST／PATCH）は、同じサイトから送られたものだけ受け付ける（Origin の確認）

### 管理者モード

設定の変更（クラス・子ども・職員・端末）は、端末の上で管理者がIDとパスワードを入れた時だけできる。
**10分たつと自動で戻る**。保育室のタブレットは誰でも触れるため、登録した管理者のまま設定が開きっぱなしにならないようにしている。

### 注意（名前を選ぶだけにしたことで生じること）

- 登録済みの端末を手にした人は、誰の名前でも記録できる（紙の記録表に名前を書くのと同じ扱い）
- 端末をなくした時は、管理者モードの「登録している端末」から、その端末の登録を解除する

## 権限

| できること | 端末（職員） | 管理者モード |
|---|---|---|
| 午睡・室温湿度の記録・閲覧・印刷 | ○ | ○ |
| クラス・子どもの登録・停止 | × | ○ |
| 職員（名前）・管理者の登録・停止 | × | ○ |
| 登録している端末の一覧・解除 | × | ○ |

確認の間隔は年齢で決まる（0歳は5分、それ以外は10分。依頼者の決定）。設定では変えられない。

削除はせず「停止」にする（過去の記録に名前を残すため）。記録の取り消しも、消さずに取り消した時刻を残す。

## 複数の端末での共有とオフライン

- 押した操作はまず端末の中で反映し、「送信待ち」に入れてからサーバーへ送る。Wi-Fi が切れても記録を続けられ、つながった時にまとめて送る
- 操作ごとに端末側でIDを付けるので、同じ操作を2回送っても二重に記録されない
- 15秒ごとにサーバーの最新の記録を取り直し、他のタブレットでの記録も反映する
- 端末に残すのは「登録した園の情報」と「送信待ちの操作」だけ。登録を解除すると消える
- 2台で同時に同じ子の午睡開始を押した場合は2件になるが、起床を押すとその子の開いている午睡がすべて閉じる

## データベース

`migrations/` の SQL を参照（番号順に適用）。

| 表 | 内容 |
|---|---|
| facilities | 園 |
| users | 職員と管理者（名前・権限・停止フラグ。管理者だけログインIDとパスワードの変換値を持つ） |
| sessions | 登録している端末（端末の名前・管理者モードの期限） |
| login_failures | ログイン失敗の記録（連続失敗の制限用） |
| classes | クラス（名前・年齢・確認間隔） |
| children | 子ども（名前・クラス・停止フラグ） |
| naps | 午睡（入眠・起床の時刻、誰が押したか） |
| nap_checks | 確認（時刻・体位・うつぶせを直したか・記録者・入力した端末・取り消し） |
| room_readings | 室温・湿度（クラス・時刻・値・記録者・入力した端末・取り消し） |
| audit_log | 管理操作の記録 |

時刻はすべてミリ秒のUNIX時刻で保存し、「何日の記録か」は日本時間で決める。

## API

| | |
|---|---|
| `POST /api/device/register` | 端末の登録（管理者のIDとパスワード・端末の名前） |
| `POST /api/device/unregister` | この端末の登録解除 |
| `GET /api/bootstrap` | 端末・園・クラス・子ども・職員の一覧、管理者モードの状態 |
| `GET /api/day?day=YYYY-MM-DD` | その日の午睡記録と室温・湿度 |
| `POST /api/ops` | 操作をまとめて送る（午睡開始・確認・取り消し・起床・室温湿度）。結果として当日の記録を返す |
| `POST /api/admin/unlock` / `lock` | 管理者モードにする／終わる |
| `/api/admin/...` | クラス・子ども・職員・端末の管理（管理者モードのみ） |

## まだやっていないこと
