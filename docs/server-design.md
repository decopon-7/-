# サーバー・ログイン・共有の設計（v0.2）

午睡チェックを「ログインした職員だけが使え、園の複数のタブレットで同じ記録を見られる」形にする。

## 構成

```
タブレット・スマホ（PWA）
   │  https
Cloudflare Workers ── 画面のファイル（app/）を配信
   │                └ /api/* を処理（worker/）
Cloudflare D1（データベース）
```

- 画面のファイルそのものには園児の情報を含めない。園児・記録のデータは、ログイン後に `/api/*` からだけ取得できる
- 1つの仕組みで複数の園を扱えるよう、すべての表に `facility_id`（園）を持たせ、**ログイン中の職員の園のデータしか読み書きできない**ようにサーバー側で絞る

## ログイン

- 職員ごとに「ログインID＋パスワード」を発行する（発行・停止は管理者だけ）
- パスワードは PBKDF2-SHA256（10万回）で変換して保存。元のパスワードは保存しない
- ログインすると、推測できない乱数の合言葉（セッション）を端末の Cookie に保存する
  - `HttpOnly`（画面のプログラムから読めない）・`Secure`（https のみ）・`SameSite=Strict`
  - データベースには合言葉そのものではなく、変換した値だけを保存する
  - 有効期限は14日。管理者は「全端末をログアウト」で一斉に無効にできる（タブレット紛失時）
- 同じログインIDで15分間に5回失敗すると、しばらくログインできなくなる
- 書き込み（POST／PATCH）は、同じサイトから送られたものだけ受け付ける（Origin の確認）

### 共有タブレットでの「記録者」

保育室のタブレットは複数の職員が交代で使う。確認のたびにログインし直すのは現場では回らないため、

- 端末には誰か1人がログインしておく
- チェックのたびに記録されるのは、画面上部で選んだ「記録者」（紙の記録表に名前を書くのと同じ扱い）
- 監査用に、**記録者**と**実際にログインしていた職員**の両方を記録に残す

## 権限

| できること | 管理者 | 職員 |
|---|---|---|
| 午睡の記録・閲覧・印刷 | ○ | ○ |
| 自分のパスワード変更 | ○ | ○ |
| クラス・確認間隔の設定 | ○ | × |
| 子どもの登録・停止 | ○ | × |
| 職員の登録・停止・パスワード再発行 | ○ | × |
| 全端末をログアウト | ○ | × |

削除はせず「停止」にする（過去の記録に名前を残すため）。記録の取り消しも、消さずに取り消した人と時刻を残す。

## 複数の端末での共有とオフライン

- 押した操作はまず端末の中で反映し、「送信待ち」に入れてからサーバーへ送る。Wi-Fi が切れても記録を続けられ、つながった時にまとめて送る
- 操作ごとに端末側でIDを付けるので、同じ操作を2回送っても二重に記録されない
- 15秒ごとにサーバーの最新の記録を取り直し、他のタブレットでの記録も反映する
- 端末に残すのは「ログイン中の園の情報」と「送信待ちの操作」だけ。ログアウトすると消える
- 2台で同時に同じ子の午睡開始を押した場合は2件になるが、起床を押すとその子の開いている午睡がすべて閉じる

## データベース

`migrations/0001_init.sql` を参照。

| 表 | 内容 |
|---|---|
| facilities | 園 |
| users | 職員（ログインID・名前・権限・パスワードの変換値・停止フラグ） |
| sessions | ログイン中の端末 |
| login_failures | ログイン失敗の記録（連続失敗の制限用） |
| classes | クラス（名前・年齢・確認間隔） |
| children | 子ども（名前・クラス・停止フラグ） |
| naps | 午睡（入眠・起床の時刻、誰が押したか） |
| nap_checks | 確認（時刻・体位・うつぶせを直したか・記録者・ログイン者・取り消し） |
| audit_log | 管理操作の記録 |

時刻はすべてミリ秒のUNIX時刻で保存し、「何日の記録か」は日本時間で決める。

## API

| | |
|---|---|
| `POST /api/login` | ログイン |
| `POST /api/logout` | ログアウト |
| `GET /api/bootstrap` | 自分・園・クラス・子ども・職員の一覧 |
| `GET /api/naps?day=YYYY-MM-DD` | その日の午睡記録 |
| `POST /api/ops` | 操作をまとめて送る（午睡開始・確認・取り消し・起床）。結果として当日の記録を返す |
| `POST /api/me/password` | 自分のパスワード変更 |
| `/api/admin/...` | クラス・子ども・職員の登録と変更、全端末ログアウト（管理者のみ） |

## まだやっていないこと

- 保護者用アプリ、出欠連絡、連絡帳
- 記録の保存期間の決定と、古い記録の書き出し
- バックアップ（D1 には過去30日に戻せる機能があるが、園として必要な保存期間は要確認）
