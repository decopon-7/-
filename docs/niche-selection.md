# ニッチ選定(日本版)

> **注意**: 以下の評価は一般的な傾向に基づく仮評価です。検索ボリューム・競合・ASP の現行単価は未検証で、実際に決める前に「5. 検証手順」で確認してください。

## 1. 評価基準(各1〜5点、競合と規制は低リスクほど高得点)
| 基準 | 内容 |
|---|---|
| 単価 | 1成約の報酬額、またはリカーリング |
| 購入意図 | 「比較」「おすすめ」「口コミ」など成約に近い検索が多いか |
| 一次情報 | 自分で使って体験・撮影できるか |
| 規制の低さ | 薬機法・金商法・保険業法・景表法のリスクが低いか |
| 競合の弱さ | 個人サイトが上位に入れる余地があるか |

## 3. 絞り込み結果
**第一候補**: #1 フリーランス・個人事業主向けツール
- 理由: 一次情報を出しやすく、規制が軽く、SaaS はリカーリング報酬の可能性がある。サブテーマ(例: 「副業会社員の開業手続き+会計ソフト」「インボイス対応の請求書ツール」)に絞れば競合を避けやすい。
- 注意: 制度改正(インボイス、電子帳簿保存法)の情報は更新が必須。

**第二候補**: #2 英語学習の特定層向け(例: 「社会人×TOEIC」「エンジニア向けビジネス英語」)
- 理由: 受講して実体験を書ける。単価が高い。
- 注意: 競合が強いため、層を細かく絞る。効果保証の断定表現は避ける。

**並行候補**: 日本発ニッチの英語サイト(日本向けeSIM・旅行・在住外国人向けサービス)
- 理由: USD 報酬になり、収益通貨を分散できる。海外版計画と併用。

## 4. 外す理由(要約)
- 金融・保険・美容: 規制と審査が重い。
- 光回線・転職: 単価は高いが、個人サイトが大手に勝つ難易度が高い。

## 5. 検証手順(決定前に必須)
1. **ASP で単価確認**: A8.net、もしもアフィリエイト、afb 等に登録し、候補ジャンルの現在の報酬・承認条件・規約を確認する。
2. **キーワード調査**: Google キーワードプランナー等で「〇〇 比較/おすすめ/口コミ」の月間検索数を50〜100語洗い出す。
3. **競合確認**: 上位10件を見て、個人サイト・新しいサイトが入っているか確認する。大手のみなら見送り。
4. **一次情報の可否**: 実際に使える・撮影できるサービスが5つ以上あるか確認する。
5. **サブテーマ決定**: 最初は1サブテーマに絞り、30〜50記事で判断する。
6. **撤退基準**: 6か月でインデックス・表示が伸びなければ見直す([business-plan-jp.md](business-plan-jp.md) の判断ルール参照)。
