# モーションガイドライン

[character-design.md](./character-design.md)の確定デザイン・確定ポーズ集を基準に、アニメーション制作会社へ渡す動きの仕様をまとめる。[channel-strategy.md](./channel-strategy.md) §1・§3の「感覚配慮設計」(急な高速カット・大音量・不規則な動きを避ける)を、実際のフレーム数・秒数レベルまで具体化したもの。

**2026-09-18更新**: 立ち上げ初期は「たねちゃん」に制作を集中する方針のため、動画テスト・検証も当面たねちゃんのみで進める。みどり先生分のプロンプト・チェック項目は仕様として残すが、実際のテストはフェーズ2再開時まで保留。

---

## 1. 基本方針

- 動きは「予測可能」「ゆったり」「大きく分かりやすい」を最優先し、リアルさや情報量の多さは狙わない
- フルアニメーション(1コマごとに絵を変える)ではなく、**リミテッドアニメーション**(主要ポーズ間をイージングでつなぐ方式)を基本とする。工数を抑えつつ、動きの予測可能性も高めやすいため相性が良い
- 制作フレームレートは24fpsを基準とするが、更新は8〜12fps相当(2〜3コマ打ち)で十分。高フレームレートでの微細な揺れは感覚過敏の子にとって逆にノイズになりうるため、あえて抑える

---

## 2. まばたき

| 項目 | たねちゃん | みどり先生 |
|---|---|---|
| 通常時の間隔 | 2〜4秒に1回(不規則な範囲でランダム化してよいが、上下限を超えない) | 4〜6秒に1回(落ち着いた印象を出すため、たねちゃんよりやや長め) |
| 動作時間 | 0.15〜0.2秒(4〜5コマ)で完結 | 同左 |
| 強調時 | 驚き・気づきの瞬間は1回だけ大きめにまばたきし、間(ま)を作ってよい | 相槌の際にゆっくり1回まばたき |

- 連続まばたきや高速点滅は使わない(1回ごとに最低1.5秒は空ける)
- 目を閉じる表情(例: [tanechan-breathing.jpg](../assets/characters/poses/tanechan-breathing.jpg)、[midori-sensei-calm.jpg](../assets/characters/poses/midori-sensei-calm.jpg))を使うカットでは、まばたきループを止めて「閉じたまま静止」に切り替える

---

## 3. 口パク(リップシンク)

キャラクターデザインのルール(表情は目・ほっぺ・口の3要素のみ)に合わせ、口の形は**3パターン**に限定する。

1. 閉じ(無音・語尾)
2. 小さく開く(通常の音節)
3. 大きく開く(強調したい音節、「はなまる」等の元気な掛け声)

- 切り替え頻度は1秒あたり3〜4回程度を上限とし、不規則な高速パカパカは避ける
- セリフが途切れたら0.2秒以内に「閉じ」へ自動復帰する
- 台本のオノマトペ(「しゅっしゅっしゅ」「すー…」「ふー…」等)は、口の開閉ではなく専用ポーズ(例: [tanechan-toothbrush.jpg](../assets/characters/poses/tanechan-toothbrush.jpg)、[tanechan-breathing.jpg](../assets/characters/poses/tanechan-breathing.jpg))側で表現し、口パクと二重の情報量にしない

---

## 4. アイドルモーション(セリフのない待機時の動き)

- **呼吸ゆれ**: 体全体を上下に約3〜5pxほどゆっくり動かす、周期2.5〜3秒。振幅は小さく、目立たせない
- **ふたば/髪の揺れ**: たねちゃんの頭上のふたば、みどり先生の前髪を、4秒周期程度でごくわずかに揺らす(そよ風程度)。生きている感じを出しつつ主張しすぎない
- 待機時間が3秒を超えるカット(例: [05_kimochi-cooldown.md](../scripts/05_kimochi-cooldown.md)の「5秒間、間を取る」)は、呼吸ゆれのみを継続し、新しいモーションを追加しない(視聴者の思考を妨げない)

---

## 5. ポーズ間のトランジション

- ポーズAからポーズBへの切り替えは、**0.3〜0.5秒のイーズイン・イーズアウト**でつなぐ。瞬間的なカット切り替え(0コマ切り替え)は使わない
- カット割り自体は台本の演出メモ通り「1カット3秒以上」を基本とする
- 万歳・ジャンプなど動きの大きいポーズ(例: [tanechan-banzai.jpg](../assets/characters/poses/tanechan-banzai.jpg))へ切り替える直前は、0.1秒程度の「ため」(わずかな沈み込み)を入れると、唐突さが減り読み取りやすくなる

---

## 6. 感情表現の強度スケール

不規則な強弱を避けるため、表情・動きの強さは**2段階**に固定する。

| 段階 | 使う場面 | 動きの目安 |
|---|---|---|
| 基本 | 通常の語り、説明 | 呼吸ゆれ+通常まばたきのみ |
| 強調(ここぞという時だけ) | 「はなまる」「できたね」等のよろこびの瞬間、驚きの瞬間 | 万歳・ジャンプ等の大きいポーズに切り替え、0.3〜0.5秒トランジション。多用しない(1本の動画で2〜3回まで) |

「強調」を多用すると視聴者が刺激に慣れて効果が薄れるほか、感覚過敏の子には疲れの原因になるため、台本上の本当のハイライトにのみ使う。

## 8. NGモーション集(絶対に避けるもの)

- 3コマ以下(0.125秒未満)での切り替え・高速点滅
- 目のハイライトの点滅、キラキラエフェクトの多用
- キャラクター全体の急激な拡大縮小(いわゆる「ズームバウンス」演出)
- 予測できない不規則なジャンプ・振動・シェイク演出
- BGM・効果音のテンポに合わない、唐突な動きの挿入
- 1本の動画内で「強調」段階のモーションを4回以上使うこと(刺激の慣れ・過多を防ぐ)

## 9. Gensparkでの動作テスト(口パク・まばたき検証)

§2・§3の数値仕様が実際の動画生成でどう再現されるかを、確定デザイン画像を起点にGensparkの動画生成機能で検証する。

### たねちゃん テスト動画プロンプト

```
添付画像のキャラクターを使って、8秒程度のループ動画を生成してください。
キャラクターは正面向きのまま、以下の動きだけをゆったり行います:

1. まばたき: 2〜4秒に1回、0.15〜0.2秒で自然にまばたきする(高速点滅・連続まばたきはしない)
2. 口の動き: 「こんにちは、たねちゃんです」と話しているように、口を
   「閉じ」「小さく開く」「大きく開く」の3パターンだけで切り替える(1秒あたり3〜4回まで、なめらかに)
3. 呼吸ゆれ: 体全体がごくわずかに上下する(周期2.5〜3秒、振幅は小さく目立たせない)
4. 頭上のふたばが4秒周期でそよ風に揺れるように、ごくわずかに動く

急なズーム、カメラの揺れ、背景の変化は加えないでください。背景は無地の生成り色(#FFF9F2)のまま静止させます。
動きは全体的にゆっくり・予測可能を最優先し、不規則な速い動き・点滅は一切使わないでください。
```

### みどり先生 テスト動画プロンプト

```
添付画像のキャラクターを使って、8秒程度のループ動画を生成してください。
キャラクターは正面向きのまま、以下の動きだけをゆったり行います:

1. まばたき: 4〜6秒に1回、0.15〜0.2秒で自然にまばたきする(たねちゃんよりやや間隔を長く、落ち着いた印象に)
2. 口の動き: 「こんにちは、みどり先生です」と話しているように、口を
   「閉じ」「小さく開く」「大きく開く」の3パターンだけで切り替える(1秒あたり3〜4回まで、なめらかに)
3. 呼吸ゆれ: 体全体がごくわずかに上下する(周期2.5〜3秒、振幅は小さく目立たせない)
4. 前髪が4秒周期でごくわずかに揺れる

急なズーム、カメラの揺れ、背景の変化は加えないでください。背景は無地の生成り色(#FFF9F2)のまま静止させます。
動きは全体的にゆっくり・予測可能を最優先し、不規則な速い動き・点滅は一切使わないでください。
```

### 検証チェックリスト

生成された動画を確認する際は、以下の観点で本仕様書とのズレをチェックする。

- [ ] まばたきの間隔・速さが指定の秒数に近いか(たねちゃん2〜4秒/みどり先生4〜6秒)
- [ ] 口の開閉が3パターン程度に収まっており、不規則な高速パカパカになっていないか
- [ ] 体の揺れ・ふたば/髪の揺れが目立ちすぎず、呼吸のように自然か
- [ ] 高速カット・フラッシュ・急なズームが紛れ込んでいないか(§8のNGモーション集に抵触しないか)
- [ ] 配色・シルエットが確定デザイン([assets/characters/](../assets/characters/))から崩れていないか

ズレが大きい場合は、プロンプトの数値表現をより具体的にする(「2秒に1回」など秒数を明示する、「ゆっくり」を強調する)か、Gensparkの生成パラメータ(動きの強さ等)を調整して再生成する。生成結果は `assets/characters/motion-tests/` に保存し、この表に検証結果を追記していく。

### テスト結果1: たねちゃん(2026-09-18)

- **動画**: [tanechan-test-01.mp4](../assets/characters/motion-tests/tanechan-test-01.mp4)(8秒・24fps)
- **確認方法**: 0.2秒間隔でフレームを抽出したコンタクトシート([tanechan-test-01-contact-sheet.jpg](../assets/characters/motion-tests/tanechan-test-01-contact-sheet.jpg))を目視確認

| 項目 | 結果 | 判定 |
|---|---|---|
| まばたきの間隔 | 約1.7秒・約4.4秒付近の2回、閉→開の遷移自体は約0.05〜0.1秒と俊敏で自然 | ○ 遷移速度は良好 |
| まばたきの保持時間 | 目を閉じた状態が**約1.5秒間**継続(1.67秒〜3.2秒)。同様に2回目も1.5秒以上継続 | ✕ 仕様の0.15〜0.2秒を大幅に超過。「ウインクして笑う」ような表情になっており、瞬きというより表情変化に見える |
| 口パク | 8秒間のうち0.88〜1.0秒付近で1回だけ口が開く動きがあり、それ以外はほぼ静止 | ✕ 仕様の「1秒あたり3〜4回切り替え」を満たしておらず、話している動きに見えない |
| 呼吸ゆれ・ふたばの揺れ | ふたばの角度がフレームごとにわずかに変化しており、自然な揺れが確認できる | ○ 概ね仕様通り |
| NGモーション | 高速カット・フラッシュ・急なズームは確認されず | ○ 問題なし |
| 配色・シルエット | 確定デザインから崩れなし | ○ 問題なし |

**総評**: 揺れ・遷移速度など「動きの質」は良好だが、まばたきは保持時間が長すぎて表情変化寄りになっており、口パクはほぼ機能していない。次のテストでは、この2点を明示的に強調したプロンプトで再生成する。

### 改善版プロンプト(たねちゃん・まばたき保持時間短縮+口パク強化)

```
添付画像のキャラクターを使って、8秒程度のループ動画を生成してください。
キャラクターは正面向きのまま、以下の動きだけをゆったり行います:

1. まばたき: 2〜4秒に1回。目を閉じている時間は0.2秒以内(コンマ数秒だけ)にしてください。
   目を閉じたまま1秒以上静止させないでください。ぱちっと閉じて、すぐ開けます。
   笑って目を細める表情ではなく、あくまで一瞬の瞬きにしてください。
2. 口の動き: キャラクターは「こんにちは、たねちゃんです」と話し続けています。
   話している間ずっと、0.2〜0.3秒ごとに口の形を
   「閉じ」→「小さく開く」→「大きく開く」→「小さく開く」…と絶え間なく切り替えてください。
   口が1秒以上動かないまま静止する瞬間を作らないでください。
3. 呼吸ゆれ: 体全体がごくわずかに上下する(周期2.5〜3秒、振幅は小さく目立たせない)
4. 頭上のふたばが4秒周期でそよ風に揺れるように、ごくわずかに動く

急なズーム、カメラの揺れ、背景の変化は加えないでください。背景は無地の生成り色(#FFF9F2)のまま静止させます。
動きは全体的にゆっくり・予測可能を最優先にしつつ、口だけは話している間ずっと動き続けるようにしてください。
```

再生成した動画も同様にコンタクトシートで検証し、上の表に「テスト結果2」として追記する。
