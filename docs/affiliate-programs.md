※報酬率や条件は頻繁に変わります。申請前に必ず公式ページで確認してください。

## ネットワーク
| 名称 | 特徴 |
|---|---|
| Impact | SaaS・Eコマース大手が多い |
| PartnerStack | SaaSのリカーリング報酬が中心 |
| Awin(ShareASale統合) | 小売・サービス幅広い |
| CJ Affiliate | 大手ブランドが多い |
| Amazon Associates | 低単価だが成約しやすい。米国居住要件・規約の確認が必要 |

## 狙い目カテゴリ
- SaaS(メール配信、会計、プロジェクト管理):リカーリング、月額課金に連動して継続報酬
- ホスティング・ドメイン:1成約$50〜$150
- VPN・セキュリティ:高単価だが競合が強い
- オンライン講座・ツール:ニッチ次第で堅い

## 選定基準
1. Cookie期間が30日以上
2. 支払いが安定(Net30〜60、最低支払額が低い)
3. リカーリング or 高単価
4. 日本からの参加・USD受取に対応
5. 規約が過度に厳しくない(ブランドキーワードの扱い等)
