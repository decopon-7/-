# 事業計画

## 1. コンセプト
- 英語圏(米国中心)の購買検討者向けに、特定ニッチの比較・レビュー・ハウツー記事を提供するサイト群を運営する。
- 収益は海外アフィリエイト報酬(USD)。広告(Mediavine/Raptive等)は後段で併用可。
- 立ち上げ後は、記事の更新・リンク切れ確認・新規記事を外注と自動化で回し、運営者の稼働を月数時間に抑える。

## 2. 現実的な前提(重要)
- 検索流入は成果まで通常6〜12か月かかる。最初の半年は収益ゼロも普通。
- 収益はプログラム規約変更・検索アルゴリズム変更で急減しうる。1社・1サイト依存は避ける。
- 「放置」だと順位が落ちる。更新・外注管理の最低限の稼働は必要。
- 収益額の保証はできない。以下の数字は仮定の試算。

## 3. ニッチ選定基準
1. 高単価または継続課金(SaaS、ホスティング、VPN、金融比較など、1成約$30〜$200以上、または月額リカーリング)
2. 検索意図が購入に近い("best X for Y"、"X vs Y"、"X review")
3. 競合が強すぎない(上位が小規模サイトでも出ている)
4. 規制リスクが低い(医療・金融は審査/規約が厳しく、初期は避ける)

## 4. 収益モデル(試算例・仮定)
| 項目 | 仮定 |
|---|---|
| 公開記事数 | 100本/サイト |
| 月間オーガニック訪問 | 20,000 |
| アフィリエイトリンククリック率 | 3% → 600クリック |
| 成約率 | 2% → 12件 |
| 平均報酬 | $60 |
| 月間収益 | 約$720/サイト |

3サイトで約$2,000/月。ただしこの到達に12〜24か月かかり、未達も十分あり得る。

## 5. 資金計画(初年度・概算)
| 項目 | 金額目安 |
|---|---|
| 法人設立(合同会社) | 約6〜10万円 |
| ドメイン・ホスティング・ツール | 約10〜20万円/年 |
| 記事制作(外注/AI下書き+編集) | 約30〜80万円 |
| 税理士 | 約15〜30万円/年 |
| 合計 | 約60〜140万円 |

## 6. マイルストーン
| 時期 | 目標 |
|---|---|
| 0-1か月 | 法人設立、口座開設、ニッチ決定、サイト公開 |
| 2-6か月 | 50〜100記事公開、各アフィリエイト承認取得 |
| 6-12か月 | 順位・クリックのデータで記事を改善、2サイト目着手 |
| 12か月〜 | 外注体制と保守チェックリストで半自動運用 |

## 7. 主なリスクと対策
| リスク | 対策 |
|---|---|
| 検索順位の変動 | 複数サイト・複数流入源(メルマガ、YouTube、Pinterest) |
| プログラム終了・報酬改定 | 1サイトで3社以上の代替を常に用意 |
| AI生成コンテンツの低品質評価 | 実体験・実機検証・編集者レビューを必須化 |
| 為替変動 | 受取は外貨口座で保持し、必要額のみ円転 |
| 規約違反(開示義務) | 全ページにアフィリエイト開示、FTCガイドに準拠 |
