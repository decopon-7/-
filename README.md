# CROWD RUSH

Mrs. GREEN APPLE

スマホブラウザで遊べる、無限に人数が増減していく「クラウドランナー」ゲームです。
道を自動で前進しながら左右にドラッグして操作し、ゲートをくぐって仲間の人数を
増やし（× や +）、時には減らしながら（− や ÷）、進路上に現れる壁を突破していきます。
壁を突破できる人数に届かなければゲームオーバー。倒れるたびにコインを獲得し、
ショップで恒久的なアップグレードを購入してまた挑戦する、というループが延々と
続く設計です。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド不要）。ローカルで確認する場合は:

```bash
python3 -m http.server 8000
```

を実行し、スマホ（または開発者ツールのモバイルエミュレーション）で
`http://<このマシンのIP>:8000/` を開いてください。

- 画面をドラッグして左右に移動
- 色付きのゲート（青=×倍率、緑=+加算、赤=−減算、橙=÷除算）を選んでくぐる
- 「◯◯必要」の壁は、そのときの人数がその数以上なら突破、足りなければゲームオーバー
- コインを集めてショップで「初期人数」「操作性」「マグネット」「ラック」を強化

## 構成

- `index.html` — 画面構成（メニュー / ゲーム画面 / ゲームオーバー / ショップ）
- `style.css` — スタイル
- `game.js` — ゲームロジック一式（Canvas 2D、外部ライブラリなしのバニラ JS）

セーブデータ（コイン・ベストスコア・アップグレード）は `localStorage` に保存されます。
