# げんきのたね TV — キッズ向けYouTubeチャンネル企画

保育士・発達支援員の専門知識を活かした、0〜6歳向けYouTubeチャンネルの立ち上げ企画リポジトリです。
キッズカテゴリーでのランキングTOP10入りを目標に、戦略・コンテンツ計画・台本・チャンネル紹介ページをまとめています。
