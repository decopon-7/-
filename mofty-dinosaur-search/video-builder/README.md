# 動画組み立てコード（切替・音つき）

Canva 連携ツールではできない **ページ切替・音の追加** を、コードで行います。
Canva から書き出した **ページ画像（PNG）** を、ffmpeg でつないで mp4 にします。

## 必要なもの
- Python 3.8 以上
- ffmpeg 4.4 以上（無ければ `pip install imageio-ffmpeg` でも可。自動で使います）

## 手順
1. Canva で **共有 → ダウンロード → PNG → すべてのページ** を選び、画像を1つのフォルダ（例 `pages/`）に入れる。
   - ファイル名の末尾の数字をページ番号として使います（例：`モフティ - 12.png` → P12）。
   - 85枚目の「素材を積み重ねたページ」は使われません（P01〜P84だけ読みます）。
2. （ガイドを直したときだけ）`python3 make_timeline.py` で `timeline.json` を作り直す。
3. 試し書き出し：
   ```
   python3 build_video.py --images pages --out test.mp4 --pages 1-14 --res 960x540 --fps 15
   ```
4. 全ページ：
   ```
   python3 build_video.py --images pages --out mofty.mp4
   ```
5. 音を入れる：`audio.example.json` をコピーして `audio.json` を作り、音声ファイルの場所と使うページを書いて、`--audio audio.json` を付ける。

## 音の書き方（audio.json）
| 項目 | 意味 |
|---|---|
| `file` | 音声ファイル（audio.json からの相対パスでよい） |
| `from_page` / `to_page` | BGM など、ページ間で流し続ける音の範囲 |
| `at_page` + `offset` | 効果音を、そのページの頭から何秒後に鳴らすか |
| `volume` | 音量（0〜1。ガイドの「音量50%」は 0.5） |
| `loop` | true で、音が短くても範囲いっぱい繰り返す |
| `fade_out` | 範囲の終わりで何秒かけて消すか |

ガイドにある効果音名（`cartoon pop` など）は、あなたが用意した音声ファイルの名前に置き換えて書いてください。

## できること / できないこと
**できる**
- ページごとの秒数どおりに並べる（本編＋エンドカードで 約6分1秒）
- ガイドの切替26箇所：ディゾルブ、サークルワイプ、カラーワイプ、マッチ&ムーブ
- BGM・効果音・声の追加（ページ位置に合わせて配置、音量、繰り返し、フェードアウト）

**代用になる（見た目が Canva と違う）**
- **マッチ&ムーブ**：素材ごとに動かすのではなく、ページ全体のズームイン／スライド／フェードで代用します。どれに当てるかは `make_timeline.py` の `MATCH_MOVE_LOOK` で変えられます。
- **カラーワイプ**：色は付かず、普通のワイプになります。
- **パンやズームのなめらかさ**：Canva のマッチ&ムーブほど自然には動きません。

**できない（画像1枚に焼き込まれているため）**
- ポップ・ライズ・ストンプ・タンブルなど、**素材ごとのアニメーション**。ここだけは Canva の画面で付けるか、素材を別々に書き出す作り（別途の開発）が必要です。
  Canva でアニメーションを付けたページを動画として書き出したい場合は、その部分は Canva 側の MP4 書き出しを使い、このコードは使わない、という選び方もあります。

## 動作確認について
- 仮の画像（色つきの四角）と仮の音声で、14ページ版と84ページ全体（合計 6:01、切替26箇所）の組み立てを確認しました。
- **本物の Canva 画像では未確認です。** また、1920×1080 での全ページ書き出しは未確認で、時間とメモリがかかる可能性があります。重いときは `--pages 1-30` のように分けて作り、あとでつなぎ直してください。
