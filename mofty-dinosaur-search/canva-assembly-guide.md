### 重ね順（レイヤー）は4つの「型」で統一
Canvaでは、あとから置いたものが手前に来ます。**下の順番どおりに置けば、重ね順は自動で正しくなります。**
もし順番がずれたら、素材を右クリック →「レイヤー」→「前面へ」「背面へ」で直します。

| 型 | 奥 → 手前の順番 | 使う場面 |
|---|---|---|
| **型A 基本** | ①背景 → ②あかちゃん恐竜 → ③モフティ → ④エフェクト（キラキラ等） → ⑤テロップ | ふつうのカット |
| **型B かくれんぼ** | ①背景 → ②**隠れている恐竜** → ③**前景パーツ**（草・岩・葉っぱ） → ④ミスリード素材 → ⑤モフティ → ⑥テロップ | 問題・探索タイム |
| **型C ヒント** | 型Bの③と⑤のあいだに**暗幕**（黒い四角・透明度40%）を入れる | ヒントのカット |
| **型D 豆知識** | ①無地の背景 → ②恐竜の全身 → ③強調パーツ（光る丸・矢印） → ④モフティ（小さめ） → ⑤テロップ | まめちしき |

> 💡 **かくれんぼのコツ**：恐竜を「背景」と「前景パーツ」で挟むと、体の一部だけが見える状態になります。見せる量は、前景パーツの位置をずらして調整します。

### 覚えておく操作は3つだけ

**① アニメーション**
素材を選ぶ → 上のツールバーの「アニメート」→ 名前を選択。ページまたは素材を選んで、ツールバーの［アニメート］から使えるアニメーションが表示されます。この指示書では、次の名前を使います：ポップ／ライズ／ドリフト／フェード／ストンプ／タンブル／パン／ワイプ。Canvaには「ポップ」「タンブル」「ストンプ」のような元気な動きと、「ドリフト」「フェード」「ブリーズ」のような穏やかな動きが用意されています。

**② ページ切り替え（トランジション）**
ページとページのあいだにマウスを乗せる →「＋」の横の切り替えボタン → 種類を選びます。種類には「ディゾルブ」「スライド」「サークルワイプ」「カラーワイプ」「ラインワイプ」「スタック」「チョップ」「フロー」「マッチ&ムーブ」があります。

**③ ズーム・パン・移動は全部「マッチ&ムーブ」で作る（最重要）**
1. ページを複製します（右クリック →「ページを複製」）。
2. 複製したほうのページで、素材を大きくしたり動かしたりします。
3. 2ページのあいだの切り替えを「マッチ&ムーブ」にします。

これで、素材がなめらかに動いて見えます。マッチ&ムーブは切り替えの一種で、ページ間の同じ素材をスムーズに動かします。写真やデザインをある場所から別の場所へ動かすパンにも使えて、切り替えの時間を変えればスピードも調整できます。

⚠️ 表示名が「マッチさせて移動」になっていることもあります。Canva Pro限定の機能です。

> 💡 **ズームするときの注意**：背景・恐竜・前景パーツを全部選んで「グループ化」してから拡大します。そうしないと、恐竜が隠れ場所からずれてしまいます。モフティとテロップはグループに入れず、その場に残します。

## 3｜仕上げのチェックリスト

- [ ] すべての**探索タイムにセリフが入っていない**（P17〜19・P34〜36・P42・P59〜60・P65〜66）
- [ ] 探索タイムのあいだは**BGMが止まり、時計音だけ**になっている
- [ ] マッチ&ムーブのページで、**恐竜が隠れ場所からずれていない**（グループ化を忘れていないか）
- [ ] テロップが**モフティの顔にかかっていない**
- [ ] スマホの小さい画面で再生しても、**隠れている恐竜が見つけられる大きさ**になっている
- [ ] 本編の尺が5分30秒〜6分に収まっている（各ページの秒数を合計すると本編は約5分51秒、エンドカードを足して約6分1秒）

**よくあるつまずき**
- **マッチ&ムーブで素材が動かない** → 前のページの素材をコピーして置き直すと、別の素材として扱われて動きません。必ず「ページを複製」してから編集してください。
- **検索したSEが見つからない** → 似た英単語で探します（例：`ding` → `chime` / `bell`）。赤ちゃん恐竜の声は、自分で録音したほうがキャラが立つのでおすすめです。

- BG-05＝夕方の森の画像、BG-06＝クリーム色 #FFF4DC の長方形、BG-07＝BG-01 の流用です。
- 頭かき＝考えるポーズ、ひらめき＝こぶし上げ、飛びつき＝バンザイ、で代用しています。
- 暗幕(PT-10)は黒40%の長方形です（P40〜42・P64〜66）。ぼかしの代わりに P81・P84 は黒35%の暗幕を重ねています。

**ツールでできないため手作業になる項目**
- アニメーション、ページ切替（マッチ&ムーブ含む）、BGM・効果音・声
- テロップの丸ゴシック化と袋文字（縁取り）
- 背景ぼかし（P08・P13・P81・P84）
- ズーム・パンのページは「拡大した状態の別ページ」として置いてあるだけです。滑らかに動かすには、前ページを「ページを複製」して作り直してください。

**確認して直した点（全ページのサムネイル確認）**
- P03・P45：キラキラ(PT-08)が小さくて見えなかったため、拡大しました。
- P07：モフティを指示書どおり高さ5割にしました。
- P70・P71：紙ふぶきでプテラが隠れていたため、プテラを大きくして手前に出しました。
