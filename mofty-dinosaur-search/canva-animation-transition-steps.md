# アニメーションとページ切替の手順（P01〜P84）

`canva-assembly-guide.md` の「アニメ」「切替」の指定を、ページ別に抜き出して操作手順をつけたものです。
**テロップや素材の配置は済んでいます。この手順では「動き」だけを付けます。**
メニュー名は Canva の更新で少し変わることがあります（見当たらなければ近い名前を探してください）。

---

## 1｜基本の操作

### アニメーションを付ける
1. 動かしたい素材（またはテロップ）を **クリックして選ぶ**。
2. 上のツールバーの **「アニメート」** を押す。
3. 一覧から名前を選ぶ（下の表の名前と同じものを探す）。
4. 種類が **「入場」「退場」「スタイル」** などに分かれていたら、**「入場」** を選ぶのが基本。
5. 動きの速さや向きを変えたいときは、選んだあとの **「オプション」** で調整する。

| ガイドの名前 | Canvaでの探し方 | 子ども向けのコツ |
|---|---|---|
| ポップ | 「ポップ」 | 弾むように出る。強すぎるなら速度を下げる |
| ライズ | 「ライズ」 | 下からふわっと上がる |
| ストンプ | 「ストンプ」 | ドンと出る。タイトルや「だい○もん」向き |
| ドリフト | 「ドリフト」 | ゆっくり漂う。手紙が落ちる動きに |
| フェード | 「フェード」 | じわっと出る／消える |
| タンブル | 「タンブル」 | 転がって出る。メダルやタイトル向き |
| ベースライン | 「ベースライン」 | 文字が下から1文字ずつ出る（テロップ向き） |

### ページ切替（トランジション）を付ける
1. ページの一覧（画面下のサムネイル）で、**切り替えたい2枚のページの間** にマウスを乗せる。
2. 出てきた **「＋」の横のボタン**（切替のマーク）を押す。
3. 一覧から種類を選ぶ（ディゾルブ／サークルワイプ／カラーワイプ／マッチ&ムーブ など）。
4. **時間** のスライダーで秒数を合わせる。
5. 「カラーワイプ」は色も選べる（緑 or オレンジ）。

> 切替は「**後ろのページ**」に付くイメージです。例：「P55→P56」なら、P55 と P56 のあいだに付けます。

### マッチ&ムーブ（ズームや移動）を成功させる
前のページと次のページで **同じ素材が、場所や大きさだけ違う** と、その間をなめらかに動いて見えます。

- Canva Pro 限定の機能です。表示が「マッチさせて移動」になっていることもあります。
- **動かない場合の対処**：まず、そのまま切替を付けて再生して確認します。素材が動かなければ、
  前のページを **「ページを複製」** → 複製したほうで素材の位置・大きさを変える → あいだに切替を付ける、で作り直します。
- ズームするページは、**背景・恐竜・前景パーツをまとめて「グループ化」してから拡大**します（そうしないと恐竜が隠れ場所からずれます）。モフティとテロップはグループに入れません。

## 3｜マッチ&ムーブの仕上げチェック

- [ ] 再生して、**恐竜が隠れ場所からずれていない**（ズームする前後で、草や岩との位置関係が同じ）
- [ ] P34→P36 のパンで、**岩とステゴが一緒に動いている**
- [ ] P63→P64 で、**見上げたあとの背景が、暗幕ページ（P64〜P66）と合っている**
- [ ] 動かないページは、前ページを複製して作り直した

## 4｜この手順に含まれないもの

- **音（BGM・効果音・声）**：`canva-manual-todo.md` の各ページの「音」を見てください。
- P21・P44・P68 などの **ズーム／パン** は、ページごとに「拡大した状態」が配置済みです。この手順の「マッチ&ムーブ」で動きだけ付けます。
