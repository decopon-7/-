# Canvaで あなたが手作業する項目（ページ別チェックリスト）

Canva連携ツールでは **配置・テロップ・画像・簡易的な暗幕/図形** までを組み立てました。次の項目はツール側で実行できないため、Canva上で手作業が必要です。

## 全ページ共通（最後にまとめて）

- [ ] 全テロップのフォントを **丸ゴシック系**、書式を **白＋袋文字（縁取り）** に変更（現状は白・太字・中央揃えまで）
- [ ] 背景ぼかし（P08・P13・P81・P84）：現状は P81/P84 に黒40%の暗幕を重ねて代用。BG画像を選び「編集→ぼかし」
- [ ] 音：BGM・SE・声（ページ別の項目を参照）
- [ ] ページ切替（トランジション）とアニメーション（ページ別の項目を参照）
- [ ] マッチ&ムーブ：ページ複製が必要な箇所は **現状は別々に配置済み** のため、前後のページで同じ素材を「同一素材」として動かしたい場合は、ページを複製して作り直してください（対象：P18→19、P35→36、P59→60、P62→63、P65→66、P67→68、P68→69 ほか）

## 代用・未達にしたもの（ツールの制約）

- ズーム／パン（P21・P34〜36・P44・P63〜64・P68 など）：背景・恐竜・前景を拡大/移動した状態で別ページとして配置済み。動きは上記の「マッチ&ムーブ」で付けてください
- BG-04（P56〜P71）：縦長 1920×2160 ではなく、お手持ちの横長画像を拡大して「上を見上げる」構図を再現
- BG-05 は夕方の森の画像 `Gemini_…r1ti4r1ti4…`、BG-06 は クリーム色 #FFF4DC の長方形、BG-07 は BG-01 を流用
- ポーズの代用：頭かき→考えるポーズ、ひらめき→こぶしを上げるポーズ、飛びつき/ハイタッチ等は近いポーズで代用
- PT-10 暗幕は黒40%の長方形（P40〜42・P64〜66）。P67 以降は暗幕なし
- 指示書の見出しは「全78ページ」ですが、実際の内容は P01〜P84 の84ページです
- 元々あった「素材を積み重ねたページ」は、動画の流れを崩さないよう P84 の後ろ（85枚目）に移動しました（削除はしていません）
