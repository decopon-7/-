# マッチ&ムーブの作り直しと最終チェック

## 1｜まず確かめること
各ペアに「マッチ&ムーブ」を付けて再生します。**素材が動いて見えればそのままでOK**です（作り直し不要）。
画面が切り替わるだけ（ふわっと入れ替わるだけ）のペアだけ、下の手順で作り直します。

## 2｜作り直しの手順（どのペアも共通）
1. **前のページ**（例：P20）を右クリック →「ページを複製」。
2. 複製されたページを、前のページの**すぐ後ろ**に置く（これが新しい「後ろのページ」）。
3. 複製ページで、下の表の素材を **選択 → 「位置」を開き、X・Y・幅・高さを入力**する。
   - X＝左端の位置、Y＝上端の位置（単位はピクセル。デザインは 1920×1080）。
   - 縦横比は崩れて構いません（表の数値どおりに入れる）。
4. 古い「後ろのページ」から、**テロップ・モフティ・暗幕など、動かさない素材をコピー**し、複製ページに貼り付ける（縁取りやアニメを付けた素材を、そのまま引き継げます）。複製ページにもともとあって不要な素材は消す。
5. 古い「後ろのページ」を削除し、複製ページとの間に **マッチ&ムーブ** を付ける。
6. 複製ページに、アニメ（ライズ・ポップなど）を付け直す。

> **ポーズが変わるペア**（P04→05、P09→10、P33→34、P37→38）は、別の画像に差し替わるので、素材は「動き」ません。マッチ&ムーブでも、位置や大きさの変化だけ滑らかに見えます。気になる場合は **「ディゾルブ」** に変えて構いません。

## 4｜最終チェック（通しで再生しながら）

### 全体
- [ ] 最初から最後まで、止まらず再生できる
- [ ] 本編の尺が 5分30秒〜6分（目安 約5分51秒、エンドカードを足して約6分1秒）
- [ ] 探索タイム（P17〜19、P34〜36、P42、P59〜60、P65〜66）に **セリフが入っていない**
- [ ] 探索タイムの間は **BGMが止まり、時計音だけ**（音を付けたあと）

### 見た目
- [ ] テロップが **モフティの顔にかかっていない**
- [ ] すべてのテロップに **丸ゴシック＋縁取り** が付いている
- [ ] スマホの小さい画面で、**隠れた恐竜が見つけられる大きさ**になっている（P15、P32、P57）
- [ ] 縁取りが薄いページ（P03・P57・P82）が読める
- [ ] 手紙（P08）が背景にじゃまされず読める
- [ ] 暗幕のページ（P40〜42、P64〜66）で、暗幕が **モフティより奥** にある

### 動き
- [ ] マッチ&ムーブのページで、**恐竜が隠れ場所からずれていない**
- [ ] P34→P36 のパンで、岩とステゴが一緒に動いている
- [ ] P68→P69 でプテラがモフティの頭の上に着地して見える
- [ ] P51〜P54 で、モフティが左右に交互に揺れて見える
