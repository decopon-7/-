# きえた あかちゃん恐竜をさがせ！(モフティ・シリーズ)

キャラクター「モフティ」が主役の、恐竜の赤ちゃんを探す謎解き系キッズ動画。全84ページ(本編 約5分50秒＋エンドカード10秒)、Canvaで「1ページ＝1カット」の紙芝居形式のアニメーションとして制作中。

**ステータス**: 制作中(Canva)。[`canva-assembly-guide.md`](./canva-assembly-guide.md)の組み立て指示書に沿って、ユーザー側でCanvaのページを組み立てている段階。

## 中身

- [`canva-assembly-guide.md`](./canva-assembly-guide.md) — シーン別・完全組み立て指示書(背景/キャラ/パーツの素材リスト、ページ別の配置・アニメーション・音・テロップ指示、仕上げチェックリスト)

## 構成概要

- オープニング(P01-P13・約47秒): モフティ登場〜事件発生〜タイトル
- 第1問 トリケラトプス(P14-P30・約68秒)
- 第2問 ステゴサウルス(P31-P55・約93秒、途中でヒント演出あり)
- 第3問 プテラノドン(P56-P74・約97秒、縦長背景でのパン演出あり)
- エンディング(P75-P84・約55秒): 全員集合、クイズ振り返り、探偵認定証、チャンネル登録導線、エンドカード

## このチャンネル企画全体との関係

[げんきのたね TV](../README.md)(たねちゃん主演、Veoでのアニメーション動画)とは別のキャラクター・別の制作方式(Canvaでの紙芝居アニメーション)によるキッズ向け動画企画。2026-10-04時点で、制作の軸足はこちらに移っている。
