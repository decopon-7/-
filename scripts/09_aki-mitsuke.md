# 台本No.9: おそとであきをみつけよう

- **シリーズ**: しぜんとはっけん
- **形式**: 長尺 / 尺目安 5分
- **対象年齢**: 3〜6歳
- **発達的ねらい**: 自然の中の色・形・音の違いに気づく観察力と、五感を使って探索する好奇心を育てる。
- **監修ポイント**: 「正解」を提示するのではなく、「なにか みつけた？」と問いかけて子供自身の発見を尊重する構成にする。

## 概要欄

```
【3歳〜6歳向け】保育士が教える、おさんぽで自然を発見する動画です。
この動画のねらい:自然の色・形・音への気づきと、五感を使った探索の力を育てます。
おさんぽや公園あそびのお供に、ぜひ一緒に「あきみつけ」をしてみてください。

▼しぜんとはっけんシリーズ再生リストはこちら
（リンク挿入）

#しぜんかんさつ #おさんぽ #知育 #保育士監修 #3歳児 #4歳児
```

## 台本本編

### [0:00-0:08] OP
(ブランドジングル。「たねちゃん」登場)

### [0:08-0:30] 導入
**たねちゃん**: 「こんにちは！たねちゃんです。きょうは おそとで『あきみつけ』をしよう。どんな いろや かたちが あるかな？」
*(ポーズ: [tanechan-wave.jpg](../assets/characters/poses/tanechan-wave.jpg))*

### [0:30-3:40] 本編(発見タイム)
*(画面に紅葉した葉っぱのイラストが登場)*

**たねちゃん**: 「あ、はっぱが あかや きいろに かわってる！さわると、どんな かんじかな？」
*(ポーズ: [tanechan-thinking.jpg](../assets/characters/poses/tanechan-thinking.jpg))*
*(3秒間の間を取り、視聴者が考える余地を作る)*

*(どんぐりのイラストが登場)*

**たねちゃん**: 「どんぐり、みつけた！まんまるの かたちと、とがった かたち、どっちも あるね。」

*(かさかさという落ち葉の音、鳥の声などの環境音を控えめに追加)*

**たねちゃん**: 「みみを すませてみて。どんな おとが きこえるかな？」
*(5秒間、環境音のみで静止。急かさない)*

**たねちゃん**: 「たねちゃんは、かさかさ〜って おとが きこえたよ。みんなは どうだった？」

### [3:40-4:30] 実践コーナー(視聴者参加)
**たねちゃん**: 「こんど おそとに いくとき、みんなも『あきみつけ』してみてね。どんな いろ、どんな かたち、みつかるかな？」
*(10秒間、想像を促す静かな間)*

### [4:30-5:00] ふりかえり+ED
**たねちゃん**: 「きょうは いろんな はっけんが あったね！」
*(ポーズ: [tanechan-banzai.jpg](../assets/characters/poses/tanechan-banzai.jpg))*
「また いっしょに はっけんしようね。バイバイ！」

## 演出・安全ガイドライン適用メモ

- 「正解」を提示せず、子供自身の気づき・発見を尊重する語りかけにする
- 環境音は控えめな音量で使用し、急な大音量・不快な高音は避ける
- 間(ま)を長めに取り、視聴者が自分のペースで観察できるようにする
- 使用ポーズの一覧は[character-design.md §6 台本対応表](../docs/character-design.md#台本対応表)を参照
