# 台本No.4: おはよう・こんにちはのあいさつうた(ショート)

- **シリーズ**: ことばとうた
- **形式**: ショート / 尺目安 30秒
- **対象年齢**: 1〜4歳
- **発達的ねらい**: 「おはよう」「こんにちは」「バイバイ」など基本の挨拶語彙を、歌とジェスチャーを通じて身につけ、社会性の基礎を育てる。
- **監修ポイント**: 挨拶は日々の生活場面(朝・出会い・別れ)ごとに使い分けが必要なため、場面のイラストを添えてセットで覚えられるようにする。

## 概要欄

```
【1〜4歳向け】おうちのひとと一緒に歌えるあいさつのうたです。
この動画のねらい:「おはよう」「こんにちは」「バイバイ」の挨拶語彙と、社会性の基礎を育てます。
続きのことばとうたシリーズは本編でも配信中！

#あいさつ #ことばとうた #1歳児 #2歳児 #知育あそび #保育士監修
```

## 演出メモ

- 30秒でも急かさず、1つの挨拶ごとにはっきり間を取って見せる
- 固定アングル・一定のBGM音量を保ち、感覚過敏の子にも配慮
- 終了カードで長尺本編(ことばとうたシリーズ)へ誘導し、回遊性を確保
- 使用ポーズの一覧は[character-design.md §6 台本対応表](../docs/character-design.md#台本対応表)を参照
