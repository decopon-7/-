# 台本No.6: 1から5までかぞえてみよう

- **シリーズ**: かず・かたち
- **形式**: 長尺 / 尺目安 4分
- **対象年齢**: 3〜5歳
- **発達的ねらい**: 1〜5の数唱と、物を1つずつ指さしながら数える「一対一対応」の力を育てる。
- **監修ポイント**: 数字を暗唱するだけでなく、実際にある物(りんご等)を1つずつ指さして数える過程を必ず見せ、数と量の対応を意識させる。

## 概要欄

```
【3歳〜5歳向け】保育士が教える、かぞえっこあそびの動画です。
この動画のねらい:1から5までの数唱と、ものを1つずつ数える力(一対一対応)を育てます。
おうちのおもちゃやおやつを使って、一緒にかぞえてみてください。

▼かず・かたちシリーズ再生リストはこちら
（リンク挿入）

#かぞえかた #すうじ #知育 #保育士監修 #3歳児 #4歳児
```

(ブランドジングル。「たねちゃん」登場)

**たねちゃん**: 「こんにちは！たねちゃんです。きょうは、かずをかぞえてみよう。1、2、3…いくつまで かぞえられるかな？」

### [0:25-3:00] 本編(りんごをかぞえる)
*(画面にりんごのイラストが1つずつ登場)*

**たねちゃん**: 「りんごが1こ。ゆびで さして、『いち』。」
*(1つ目のりんごを指さす演出、テロップ「1」)*

**たねちゃん**: 「もう1こ ふえたよ。『いち、に』。」
*(2つ目が加わる、順番に指さしながら数える演出を継続)*

*(同様に3、4、5まで1つずつ増やしながら数える。急かさず、1つ増えるごとに1〜2秒の間を取る)*


## 演出・安全ガイドライン適用メモ

- 数を1つ増やすごとに必ず間を取り、急いで進めない
- テロップの数字はひらがなの読み仮名を添え、視覚的にも数と量が対応して見えるようにする
- カット割り・音量ルールは全シリーズ共通(1カット3秒以上、急な音量変化を避ける)
- 使用ポーズの一覧は[character-design.md §6 台本対応表](../docs/character-design.md#台本対応表)を参照
