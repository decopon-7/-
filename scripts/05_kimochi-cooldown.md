# 台本No.5: イライラしたときのクールダウン呼吸法

- **シリーズ**: きもちのじかん
- **形式**: 長尺 / 尺目安 4分
- **対象年齢**: 3〜6歳
- **発達的ねらい**: 自分の気持ちに名前をつける力(感情語彙)と、気持ちが高ぶったときに落ち着く方法(セルフレギュレーション)を、具体的な動作(呼吸法)を通して体得する。
- **監修ポイント**: 発達支援の現場で使われる「見える化した感情メーター」や「動作を伴う呼吸法」を取り入れる。感覚過敏の子にも配慮し、演出は終始落ち着いたトーンで統一する。

## 概要欄

```
【3歳〜6歳向け】イライラ・モヤモヤした気持ちとの付き合い方を、保育士・発達支援員が一緒に伝える動画です。
この動画のねらい:気持ちに名前をつけること、深呼吸で自分を落ち着かせる方法を身につけます。
癇癪が出やすいお子さんや、気持ちの切り替えが苦手なお子さんにもおすすめです。

#きもちのきょういく #感情教育 #発達支援 #アンガーマネジメント #保育士監修
```

## 台本本編

### [0:00-0:10] OP
(通常より音量・テンポを2割ほど落とした「きもちのじかん」専用OP)

### [0:10-0:40] 導入
**たねちゃん**: 「ねえ、みんな。おもちゃ とられちゃったり、おもいどおりにいかなくて、むかむか〜っとすること、ある？たねちゃんも、あるんだ。そんなときのこと、きょうはいっしょにかんがえてみよう。」

*(テロップ: 「むかむか、あるよね」やさしいフォントで表示)*

### [0:40-1:30] 気持ちの見える化(感情メーター)
*(画面に「きもちメーター」イラスト登場: にこにこ→ふつう→もやもや→かんかん の4段階、色は暖色〜寒色ではなく統一トーンのグラデーションで表現し、過度な刺激を避ける)*

**たねちゃん**: 「きもちには、いろんな おおきさがあるんだよ。にこにこ、ふつう、もやもや、かんかん。いまのじぶんは、どれかな？こころのなかで、かんがえてみてね。」
*(ポーズ: [tanechan-thinking.jpg](../assets/characters/poses/tanechan-thinking.jpg) 小首をかしげて考えるポーズを使用)*

*(5秒間、間を取る。急かさない)*

**たねちゃん**: 「もやもや や かんかん になったとき、じぶんの きもちに『あ、いま、もやもやしてるな』って きづくのが、だいいっぽなんだ。」

### [1:30-3:00] クールダウン呼吸法
**たねちゃん**: 「もやもやを、すこし ちいさくする まほうを おしえるね。『はなのにおい・ろうそく』こきゅうほう、やってみよう。」

*(画面演出: たねちゃんの手元に「お花」と「ろうそく」のイラスト小道具。ゆっくりとした動作)*

**たねちゃん**: 「まず、おはなの においを かぐみたいに、はなから すー…と すってみて。」
*(ポーズ: [tanechan-breathing.jpg](../assets/characters/poses/tanechan-breathing.jpg) お花のにおいをかぐポーズを使用。4秒キープ、テロップ「すー…」)*

**たねちゃん**: 「つぎは、ろうそくの ひを けすみたいに、くちから ふー…っと はいてみよう。」
*(6秒キープ、テロップ「ふー…」)*

**たねちゃん**: 「じょうずだね。もういっかい、いっしょに。すー…、ふー…」
*(2回目、視聴者と一緒にリズムをそろえる。BGMは終始一定・穏やかなトーン)*

### [3:00-3:40] ふりかえり
**たねちゃん**: 「どう？すこし、きもちが おちついたかな？もやもやしたときは、いつでも このこきゅうほう、つかってみてね。じぶんの きもちに きづいて、おちつく ほうほうを しってるって、とっても すてきなことなんだよ。」

*(否定・評価をしない。「うまくできなくても大丈夫」という趣旨のセリフを添える)*

**たねちゃん**: 「れんしゅうちゅうでも、だいじょうぶ。なんかいも やってみようね。」

### [3:40-4:00] ED
**たねちゃん**: 「きょうも いっしょに ありがとう。つぎの『きもちのじかん』も みてね。バイバイ！」

## 演出・安全ガイドライン適用メモ

- 全編を通してBGM・効果音は一定音量、急な変化・大音量を避ける(感覚過敏への配慮)
- 「間」を意図的に長めに取り、視聴者が自分のペースで呼吸法を試せるようにする
- 感情メーターは断定的な診断表現を避け、「気持ちには大きさがある」というニュートラルな伝え方に統一
- 保護者向け補足として概要欄に「気になる場合は保育士・発達相談窓口へ」の一文を追加する運用ルールを推奨(コンプライアンス方針: [channel-strategy.md](../docs/channel-strategy.md) §6参照)
- 使用ポーズの一覧は[character-design.md §6 台本対応表](../docs/character-design.md#台本対応表)を参照
