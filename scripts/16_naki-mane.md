# 台本No.16: どうぶつのなきまねうた(ショート)

- **シリーズ**: ことばとうた
- **形式**: ショート / 尺目安 30秒
- **対象年齢**: 1〜3歳
- **発達的ねらい**: 動物の鳴き声を真似ることで語彙を拡張し、模倣・表現力を育てる。
- **監修ポイント**: 鳴き声の音量は控えめにし、驚かせるような急な大音量は使わない。動物ごとに十分な間を取り、真似する時間を確保する。

## 概要欄

```
【1〜3歳向け】おうちのひとと一緒に遊べる、どうぶつのなきまねうたです。
この動画のねらい:動物の鳴き声の模倣を通じて語彙を広げ、表現力を育てます。

#どうぶつ #なきまね #ことばとうた #1歳児 #2歳児 #知育あそび #保育士監修
```
