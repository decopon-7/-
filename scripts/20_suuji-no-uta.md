# 台本No.20: すうじのうた 1〜10

- **シリーズ**: かず・かたち
- **形式**: 長尺 / 尺目安 4分
- **対象年齢**: 3〜6歳
- **発達的ねらい**: 1から10までの数唱を、歌のリズムに乗せて記憶しやすい形で獲得する。
- **監修ポイント**: [06_kazoeyou.md](./06_kazoeyou.md)で身につけた1〜5の一対一対応の力を土台に、6〜10まで数の範囲を広げる「発展編」として位置づける。

## 概要欄

```
【3歳〜6歳向け】保育士が教える、すうじのうた1から10までの動画です。
この動画のねらい:1から10までの数唱を、歌のリズムで楽しく身につけます。
「1から5までかぞえてみよう」の次のステップとしてもおすすめです。

▼かず・かたちシリーズ再生リストはこちら
（リンク挿入）

#すうじのうた #かぞえかた #知育 #保育士監修 #4歳児 #5歳児
```

## 台本本編

### [0:00-0:08] OP
(ブランドジングル。「たねちゃん」登場)

### [0:08-0:25] 導入
**たねちゃん**: 「こんにちは！たねちゃんです。きょうは、1から10まで、すうじのうたを うたってみよう。」
*(ポーズ: [tanechan-thinking.jpg](../assets/characters/poses/tanechan-thinking.jpg))*

### [0:25-3:00] 本編(すうじのうた)
♪すうじのうた(オリジナル/やさしいテンポ)
```
いち に さん し ご
ろく しち はち きゅう じゅう
すうじを うたって おぼえよう
ゆびを おりながら いってみよう
```

**たねちゃん**: 「1から5までは、もう じょうずに かぞえられたね。きょうは、6から10まで、いっしょに いってみよう。」
*(テロップに数字を1つずつ大きく表示、指折りのジェスチャーを添える)*

**たねちゃん**: 「ろく、しち、はち、きゅう、じゅう！」
*(1つずつ間を取りながら進行、急がない)*

**たねちゃん**: 「じゃあ、さいしょから とおしで うたってみよう。いち、に、さん…」
*(1〜10を通しでゆっくり歌う)*

### [3:00-3:40] 実践コーナー(視聴者参加)
**たねちゃん**: 「じゃあ、いっしょに うたってみよう！ゆびを おりながら、いち、に、さん…」
*(15秒間、一緒に数える時間を確保)*

## 演出・安全ガイドライン適用メモ

- [06_kazoeyou.md](./06_kazoeyou.md)との連続性を意識し、同じテンポ・同じ指折りジェスチャーで統一する
- 6〜10は新しく覚える範囲のため、1つずつ間を取り急がない
- カット割り・音量ルールは全シリーズ共通(1カット3秒以上、急な音量変化を避ける)
- 使用ポーズの一覧は[character-design.md §6 台本対応表](../docs/character-design.md#台本対応表)を参照
