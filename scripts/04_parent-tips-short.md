# 台本No.10: 「イヤイヤ期」との向き合い方(保護者向けショート)

- **シリーズ**: ほいくしのワンポイント
- **形式**: ショート / 尺目安 60秒
- **対象**: 保護者向け(子供の視聴も妨げない穏やかなトーン)
- **狙い**: 保護者の育児不安を軽減し、専門性への信頼を獲得する。SNSシェアされやすい「明日から使える1つのコツ」形式にする。
- **監修ポイント**: 断定的な「正解」を押し付けず、保育現場での実践例として提示する。共感→具体策→まとめの3段構成。

## 概要欄

```
【保護者向け】保育士が教える、イヤイヤ期の向き合い方のコツを60秒でお伝えします。
この動画のねらい:保護者の育児不安を少しでも軽くし、明日から使える関わり方のヒントをお届けします。

▼ほいくしのワンポイントシリーズ再生リストはこちら
（リンク挿入）

#イヤイヤ期 #育児 #保育士のアドバイス #子育てのヒント #発達支援
```

---

## 構成・台本

| 時間 | 内容 |
|---|---|
| 0:00-0:05 | フック(共感の一言) |
| 0:05-0:15 | 課題提示 |
| 0:15-0:45 | 具体的なコツ(2つ) |
| 0:45-0:60 | まとめ+チャンネル誘導 |

### [0:00-0:05] フック
**保育士(顔出し/肩書きテロップ表示: 「保育士歴12年」)**:
「『イヤ！』しか言わない毎日、しんどいですよね。」

### [0:05-0:15] 課題提示
「イヤイヤ期は、成長の証。でも、毎日向き合う保護者は本当に大変です。今日は現場で使っている2つのコツをお伝えします。」

### [0:15-0:45] 具体的なコツ
**コツ1「選択肢を2つ渡す」**
「『着替えて』ではなく、『赤い服と青い服、どっちにする？』と聞いてみてください。“選ぶ”という主導権を渡すだけで、応じやすくなることが多いです。」
*(テロップ: 「①せんたくしを2つわたす」)*

**コツ2「気持ちを先に言葉にする」**
「『イヤだったね』と気持ちを代弁してから、次の行動を伝える。順番を変えるだけで、お子さんの気持ちが落ち着きやすくなります。」
*(テロップ: 「②きもちを さきに ことばにする」)*

### [0:45-0:60] まとめ+誘導
「うまくいかない日があっても大丈夫。完璧じゃなくていいんです。続きのヒントはチャンネルの『ほいくしのワンポイント』でまた紹介します。」
*(画面下部: チャンネル登録ボタン+再生リストへの誘導カード)*

---

## 演出メモ

- 保育士本人の顔出し・肩書きテロップを毎回統一フォーマットで表示し、E-E-A-T(専門性・信頼性)を積み上げる
- 断定表現(「〜すべき」「〜が正解」)を避け、「現場ではこうしています」という提案ベースの語り口にする
- 最後は必ず「完璧でなくてよい」という保護者を追い詰めないメッセージで締める
