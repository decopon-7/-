# 台本No.13: トイレさん、こんにちは

- **シリーズ**: せいかつしゅうかん
- **形式**: 長尺 / 尺目安 4分
- **対象年齢**: 2〜4歳
- **発達的ねらい**: トイレという場所・行為への不安を減らし、見通しを持って取り組めるようにする(トイレトレーニングの導入支援)。
- **監修ポイント**: トイレを「こわいところ」ではなく「あいさつする相手」として擬人化し、親しみを持たせる。失敗を責めない言葉選びを徹底する。

## 概要欄(投稿時にそのまま使用)

```
【2歳〜4歳向け】保育士が教える、トイレトレーニングを応援する動画です。
この動画のねらい:トイレへの不安を減らし、見通しを持って取り組む力を育てます。
トイレを嫌がるお子さんにもおすすめ。おうちのトイレでも「こんにちは」してみてくださいね。

▼せいかつしゅうかんシリーズ再生リストはこちら
（リンク挿入）

#トイレトレーニング #生活習慣 #知育 #保育士監修 #2歳児 #3歳児
```

## 台本本編

(ブランドジングル。「たねちゃん」登場)

**たねちゃん**: 「こんにちは！たねちゃんです。きょうはね、『トイレさん』に ごあいさつ しに いくよ。」

### [0:25-2:40] 本編

*(テロップ「①トイレさんにこんにちは」ハイライト)*

*(テロップ「②ズボンをおろす」ハイライト)*

*(テロップ「③すわる」ハイライト)*

### [2:40-3:30] 実践コーナー(視聴者参加)
**たねちゃん**: 「じゃあ、いっしょに トイレさんに あいさつ しにいこう！トイレさん、こんにちは！」
*(15秒間、実演を促す静かな待ち時間。急かさない)*
**たねちゃん**: 「できたかな？」

### [3:30-4:00] ふりかえり+ED
**たねちゃん**: 「トイレさんに あいさつ できたひとも、まだ れんしゅうちゅうの ひとも、みんな はなまるだよ。」
*(ポーズ: [tanechan-banzai.jpg](../assets/characters/poses/tanechan-banzai.jpg))*
*(失敗や個人差を否定的に扱わない表現を徹底)*
「またいっしょに いこうね。バイバイ！」

## 演出・安全ガイドライン適用メモ

- トイレを擬人化し、親しみやすい存在として描く(こわい・恥ずかしいという印象を与えない)
- 「できなくても大丈夫」というメッセージを必ず含め、個人差へのプレッシャーを与えない
- カット割り・音量ルールは全シリーズ共通(1カット3秒以上、急な音量変化を避ける)
- 使用ポーズの一覧は[character-design.md §6 台本対応表](../docs/character-design.md#台本対応表)を参照
