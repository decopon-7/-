# 台本No.8: おきがえバッチリ選手権

- **シリーズ**: せいかつしゅうかん
- **形式**: 長尺 / 尺目安 3分
- **対象年齢**: 2〜4歳
- **発達的ねらい**: 着替えの順序(下着→上着→ズボン)を意識し、自分の手で最後まで取り組む自立心を育てる。
- **監修ポイント**: 「選手権」という遊び要素で、着替えを競争や失敗のプレッシャーにせず「楽しいチャレンジ」として提示する。順序を問うクイズ形式で見通しを持たせる。

## 概要欄(投稿時にそのまま使用)

```
【2歳〜4歳向け】保育士が教える、おきがえがじょうずになる動画です。
この動画のねらい:着替えの順序を見通し、自分で最後まで取り組む力を育てます。
「おきがえバッチリ選手権」で、楽しく着替えの練習をしてみましょう。

▼せいかつしゅうかんシリーズ再生リストはこちら
（リンク挿入）

#おきがえ #生活習慣 #知育 #保育士監修 #2歳児 #3歳児
```

## 演出・安全ガイドライン適用メモ

- 「選手権」はあくまで自己チャレンジの演出であり、他者との比較・順位づけは行わない
- 手順クイズの正解発表前に必ず間を取り、子供が考える時間を作る
- カット割り・音量ルールは全シリーズ共通(1カット3秒以上、急な音量変化を避ける)
- 使用ポーズの一覧は[character-design.md §6 台本対応表](../docs/character-design.md#台本対応表)を参照
