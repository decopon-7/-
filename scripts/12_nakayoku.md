# 台本No.12: ともだちとなかよく〜貸して・いいよ〜

- **シリーズ**: きもちのじかん
- **形式**: 長尺 / 尺目安 5分
- **対象年齢**: 3〜6歳
- **発達的ねらい**: おもちゃの取り合いなどのトラブル場面で使える「かして」「いいよ」「あとでね」といった言葉を身につけ、友達との関わり方(社会性)を育てる。
- **監修ポイント**: どちらが悪いという評価をせず、「こう言うと伝わりやすいよ」という具体的な言葉の提案として伝える。保育現場での実際のトラブル対応の型を反映する。

## 概要欄

```
【3歳〜6歳向け】保育士が教える、お友達となかよく遊ぶためのことばを伝える動画です。
この動画のねらい:「かして」「いいよ」「あとでね」など、トラブル場面で使える言葉と社会性を育てます。
お友達とのおもちゃの取り合いで悩んだときに、ぜひ一緒に見てみてください。

▼きもちのじかんシリーズ再生リストはこちら
（リンク挿入）

#おともだち #きもちのきょういく #社会性 #保育士監修 #発達支援
```

## 台本本編

### [0:00-0:10] OP
(通常より音量・テンポを2割ほど落とした「きもちのじかん」専用OP)

### [0:10-0:40] 導入
**たねちゃん**: 「ねえ、みんな。おもちゃで あそびたいのに、おともだちが つかっていて、かしてほしいとき、ある？たねちゃんも、そういうとき あるんだ。」
*(ポーズ: [tanechan-thinking.jpg](../assets/characters/poses/tanechan-thinking.jpg))*

### [0:40-2:00] 気持ちの見える化
**たねちゃん**: 「つかいたいのに つかえないと、もやもや するよね。でも、いきなり とっちゃうと、おともだちも かなしい きもちに なっちゃうんだ。」

*(5秒間、間を取る)*

**たねちゃん**: 「そんなとき、つかえる まほうの ことば、おしえるね。」

### [2:00-4:00] ことばの練習
**たねちゃん**: 「まず、『かして』。つかいたいときは、こう いってみよう。」
*(テロップ「①かして」)*

**たねちゃん**: 「かしてもらったら、『いいよ』。じぶんが つかっているときも、こたえてみよう。」
*(テロップ「②いいよ」)*

**たねちゃん**: 「いま つかっていて わたせないときは、『あとでね』。これも だいじな ことばなんだ。」
*(テロップ「③あとでね」)*

**たねちゃん**: 「じゃあ、いっしょに いってみよう。『かして』『いいよ』『あとでね』。」
*(視聴者と一緒に3つの言葉を繰り返す。急かさず1つずつゆっくり)*

### [4:00-4:40] ふりかえり
**たねちゃん**: 「まほうの ことば、つかえそうかな？さいしょは うまく いえなくても だいじょうぶ。れんしゅうちゅうでも、はなまるだよ。」
*(否定・評価をしない語りかけを徹底)*

### [4:40-5:00] ED
**たねちゃん**: 「きょうも いっしょに ありがとう。つぎの『きもちのじかん』も みてね。バイバイ！」
*(ポーズ: [tanechan-banzai.jpg](../assets/characters/poses/tanechan-banzai.jpg))*

## 演出・安全ガイドライン適用メモ

- どちらか一方を悪者にする描写はせず、両方の気持ちを尊重した提示にする
- 「間」を意図的に長めに取り、視聴者が自分の経験と重ねられるようにする
- BGM・効果音は一定音量、急な変化・大音量を避ける(感覚過敏への配慮)
