# 台本No.14: おおきい・ちいさい くらべっこ(ショート)

- **シリーズ**: かず・かたち
- **形式**: ショート / 尺目安 40秒
- **対象年齢**: 2〜4歳
- **発達的ねらい**: 「おおきい・ちいさい」という比較の概念と、その語彙を育てる。
- **監修ポイント**: 2つのものを並べて直接見比べることで、抽象的な比較概念を具体物と結びつけて理解しやすくする。

## 概要欄

```
【2〜4歳向け】おおきい・ちいさいをくらべっこするあそびです。
この動画のねらい:大小を見比べる比較の概念と、そのことばを育てます。
```
