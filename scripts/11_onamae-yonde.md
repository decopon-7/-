# 台本No.11: おなまえよんで！はーい手遊び(ショート)

- **シリーズ**: ことばとうた
- **形式**: ショート / 尺目安 30秒
- **対象年齢**: 0〜2歳
- **発達的ねらい**: 名前を呼ばれたら反応する自己認識の力と、「はーい」と返事をする言葉のやりとりの基礎を育てる。
- **監修ポイント**: 特定の名前ではなく「〇〇ちゃん」のように、視聴者が自分の名前に置き換えて楽しめる余白を残す。

## 概要欄

```
【0〜2歳向け】おうちのひとと一緒に遊べる、おなまえよびかけ手遊びです。
この動画のねらい:名前を呼ばれて反応する力、「はーい」の返事のやりとりを育てます。
おうちのひとに、お子さんのお名前を呼んでもらいながら見てくださいね。

#手遊び歌 #おなまえ #0歳児 #1歳児 #2歳児 #知育あそび #保育士監修
```

## 演出メモ

- 名前を呼ぶ間(ま)を十分に取り、おうちのひとが実際に呼びかける時間を確保する
- 固定アングル・一定のBGM音量を保ち、感覚過敏の子にも配慮
