# 台本No.15: みずのあそび、ひえひえ・あったか

- **シリーズ**: しぜんとはっけん
- **形式**: 長尺 / 尺目安 4分
- **対象年齢**: 2〜5歳
- **発達的ねらい**: 水の温度(冷たい・温かい)を感じる感覚あそびを通じて、触覚の言葉(ひえひえ・あったか等)を育てる。
- **監修ポイント**: 感覚あそびは個人差・過敏さがあるため、無理に触らせる演出は避け、「見るだけでも楽しめる」構成にする。

## 概要欄

```
【2歳〜5歳向け】保育士が教える、みずのかんしょくあそび動画です。
この動画のねらい:水の温度を感じる感覚あそびを通じて、触覚の言葉を育てます。
おうちでの水遊び・お風呂の時間にもおすすめです。

▼しぜんとはっけんシリーズ再生リストはこちら
（リンク挿入）

#みずあそび #かんかくあそび #知育 #保育士監修 #2歳児 #3歳児
```

## 台本本編

### [0:00-0:08] OP
(ブランドジングル。「たねちゃん」登場)

### [0:08-0:25] 導入
**たねちゃん**: 「こんにちは！たねちゃんです。きょうは『みずのあそび』。ひえひえの みずと、あったかい みず、どっちも あるんだよ。」
*(ポーズ: [tanechan-wave.jpg](../assets/characters/poses/tanechan-wave.jpg))*

### [0:25-2:40] 本編
*(画面に氷水のコップが登場)*

**たねちゃん**: 「これは、ひえひえの おみず。さわると、つめたいんだ。」
*(ポーズ: [tanechan-breathing.jpg](../assets/characters/poses/tanechan-breathing.jpg) 手を近づけて感触を確かめるしぐさとして使用)*

*(画面にぬるま湯のコップが登場)*

**たねちゃん**: 「こっちは、あったかい おみず。ぽかぽか きもちいいね。」

**たねちゃん**: 「ひえひえと あったか、どっちが すき？こころのなかで かんがえてみてね。」
*(5秒間、間を取る。急かさない)*

*(水しぶき・水面の揺れなど、視覚的に涼しげな演出を軽く追加。音量は控えめ)*

### [2:40-3:30] 実践コーナー(視聴者参加)
**たねちゃん**: 「おうちのひとと いっしょに、おみずに さわってみてもいいかな？むりせず、みるだけでも だいじょうぶだよ。」
*(10秒間、想像・実演を促す静かな間)*

### [3:30-4:00] ふりかえり+ED
**たねちゃん**: 「ひえひえも あったかも、どっちも きもちいいね！」
*(ポーズ: [tanechan-banzai.jpg](../assets/characters/poses/tanechan-banzai.jpg))*
「また いっしょに あそぼうね。バイバイ！」

## 演出・安全ガイドライン適用メモ

- 感覚過敏の子への配慮として、「さわらなくても、みるだけでも大丈夫」という選択肢を必ず提示する
- 水音・水しぶきの効果音は控えめな音量に固定し、急な水音の変化は避ける
- カット割り・音量ルールは全シリーズ共通(1カット3秒以上、急な音量変化を避ける)
- 使用ポーズの一覧は[character-design.md §6 台本対応表](../docs/character-design.md#台本対応表)を参照
