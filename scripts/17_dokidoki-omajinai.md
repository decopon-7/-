# 台本No.17: どきどきしたときのおまじない(ショート)

- **シリーズ**: きもちのじかん
- **形式**: ショート / 尺目安 45秒
- **対象年齢**: 3〜6歳
- **発達的ねらい**: 初めての場所や新しい状況で感じる不安・緊張(どきどき)に気づき、簡単な自己調整の方法を身につける。
- **監修ポイント**: [05_kimochi-cooldown.md](./05_kimochi-cooldown.md)の呼吸法シリーズの短縮版として、より短い場面(発表会前、初めての場所など)でも使える「おまじない」形式にする。

## 概要欄

```
【3歳〜6歳向け】どきどきしたときに使える、おまじないを紹介する動画です。
この動画のねらい:不安・緊張に気づき、簡単な自己調整の方法を身につけます。
発表会の前や、初めての場所へ行く前にもおすすめです。

#きもちのきょういく #どきどき #発達支援 #保育士監修
```
