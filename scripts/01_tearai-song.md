# 台本No.1: 保育士が教える手洗いソング

- **シリーズ**: せいかつしゅうかん
- **形式**: 長尺 / 尺目安 3分
- **対象年齢**: 1〜3歳
- **発達的ねらい**: 手洗いの手順(ぬらす→あわ立て→こする→すすぐ→ふく)を歌で覚え、生活習慣の自立につなげる。
- **監修ポイント**: 手順を5ステップに単純化し、毎回同じ歌・同じ順番で繰り返すことで、家庭でも再現しやすくする。低年齢向けのため、1ステップずつ「まって」から次に進む間を必ず取る。

## 概要欄(投稿時にそのまま使用)

```
【1歳〜3歳向け】保育士が教える、てあらいがじょうずになる歌です。
この動画のねらい:手洗いの手順を歌で覚え、生活習慣の自立につなげます。
おでかけのあと、ごはんの前など、毎日のてあらいタイムにぜひ一緒に歌ってみてください。

▼せいかつしゅうかんシリーズ再生リストはこちら
（リンク挿入）

#てあらい #生活習慣 #知育 #保育士監修 #1歳児 #2歳児
```

## 台本本編

### [0:00-0:08] OP
(ブランドジングル。アニメキャラクター「たねちゃん」登場)

### [0:08-0:20] 導入
**たねちゃん**: 「こんにちは！たねちゃんです。きょうは『てあらい』のうた、いっしょにうたおうね。」
*(ポーズ: [tanechan-wave.jpg](../assets/characters/poses/tanechan-wave.jpg))*

*(テロップ: 「てあらい5つのステップ ①ぬらす②あわあわ③ごしごし④すすぐ⑤ふく」を先に提示)*

### [0:20-2:20] 本編(てあらいのうた)

♪てあらいのうた(オリジナル/やさしいテンポ)
```
おみずで ぬらして
せっけん あわあわ
てのひら てのこう ごしごし
ゆびのあいだも わすれずに
すすいで さいごは ふいたらば
ぴかぴか てあらい できました
```

**たねちゃん**: 「まずは、おみずで ぬらしてみよう。」
*(テロップ「①ぬらす」ハイライト、3秒待つ)*

**たねちゃん**: 「つぎは、せっけんで あわあわ〜。」
*(テロップ「②あわあわ」ハイライト)*

**たねちゃん**: 「てのひらも、てのこうも、ごしごし ごしごし。ゆびのあいだも わすれないでね。」
*(テロップ「③ごしごし」ハイライト)*

**たねちゃん**: 「さいごは、おみずで すすいで、タオルで ふいたら…ぴかぴか てあらい できました！」
*(テロップ「④すすぐ⑤ふく」順にハイライト)*

### [2:20-2:45] 実践コーナー(視聴者参加)
**たねちゃん**: 「じゃあ、いっしょにやってみよう！おみず、じゃー。3、2、1…」
*(10秒間、実演を促す静かな待ち時間)*
**たねちゃん**: 「あわあわ できたかな？」

### [2:45-3:00] ふりかえり+ED
**たねちゃん**: 「ぴかぴかの おてて、みせてね！じょうずにできたね、はなまる！」
*(ポーズ: [tanechan-banzai.jpg](../assets/characters/poses/tanechan-banzai.jpg))*
「またあおうね、バイバイ！」

## 演出・安全ガイドライン適用メモ

- カット割りは1カット3秒以上、高速点滅・急なズームは使用しない
- BGM・効果音は一定音量を保ち、急激な変化を避ける
- テロップはひらがな中心・大きめフォント、読み上げと同期
- 実践コーナーの待ち時間を必ず確保し、低年齢の子供のペースを尊重する
- 使用ポーズの一覧は[character-design.md §6 台本対応表](../docs/character-design.md#台本対応表)を参照
