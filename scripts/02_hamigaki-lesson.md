# 台本No.2: はみがきレッスン〜イヤイヤさんも大丈夫〜

- **シリーズ**: せいかつしゅうかん
- **形式**: 長尺 / 尺目安 4分
- **対象年齢**: 2〜5歳
- **発達的ねらい**: 歯磨きへの抵抗感を減らし、見通しを持って自分から取り組む力を育てる。手順を「順番」として覚え、生活習慣の自立につなげる。
- **監修ポイント**: イヤイヤ期の子供が「やらされる」のではなく「自分でやりたい」と思えるよう、選択肢を与える語りかけ(保育現場の「肯定的行動支援」の手法)を随所に入れる。

## 概要欄(投稿時にそのまま使用)

```
【2歳〜5歳向け】保育士が教える、はみがきが好きになる動画です。
この動画のねらい:歯磨きの手順を見通し、自分から取り組む気持ちを育てます。
「イヤイヤ」で歯磨きを嫌がるお子さんにもおすすめ。おうちでぜひ一緒にやってみてください。

▼せいかつしゅうかんシリーズ再生リストはこちら
（リンク挿入）

#はみがき #生活習慣 #知育 #保育士監修 #2歳児 #3歳児
```

## 台本本編

### [0:00-0:10] OP
(ブランドジングル。アニメキャラクター「たねちゃん」が画面中央に登場)

### [0:10-0:25] 導入
**たねちゃん**: 「こんにちは！たねちゃんです。今日はね、『はみがき』のじかん！はみがき、とくいなひと〜？ちょっとにがてなひとも、だいじょうぶ。じゅんばんに、いっしょにやってみようね。」
*(ポーズ: [tanechan-wave.jpg](../assets/characters/poses/tanechan-wave.jpg) 「こんにちは」の手を振るポーズを使用)*

*(画面下部テロップ: 「きょうのじゅんばん①はぶらしをもつ②した ③うえ④うがい」を先に提示し、見通しを持たせる)*

### [0:25-2:30] 本編(手順×歌)

**たねちゃん**: 「まず、はぶらしさん、もってみよう。もてたひと、はなまる！」
*(効果音: きらきら音。テロップ「①はぶらしをもつ」ハイライト)*

**たねちゃん**: 「つぎは、したのは。しゅっしゅっしゅ〜(ゆっくり口を大きく開けて実演)」
*(ポーズ: [tanechan-toothbrush.jpg](../assets/characters/poses/tanechan-toothbrush.jpg) 歯ブラシを持つポーズを、本編中このパートで一貫して使用)*

♪はみがきうた(オリジナル/やさしいテンポ・急なリズム変化なし)
```
しゅっしゅっしゅ したのは
しゅっしゅっしゅ うえのは
まえも うしろも きれいにね
ピカピカ えがお ばんざーい
```

**たねちゃん**: 「じょうずだね！つぎは、うえのは。おなじように、しゅっしゅっしゅ〜」
*(テロップ「②した ③うえ」順にハイライト、進行を可視化)*

**たねちゃん**: 「さいごは、うがい。ぶくぶくぺー！」
*(効果音は控えめ・大音量にしない。急な音量変化を避ける設計)*

### [2:30-3:20] 実践コーナー(視聴者参加)
**たねちゃん**: 「じゃあ、いまから、おうちのひとと いっしょにやってみよう！はぶらし、もってきてね。3、2、1、しゅっしゅっしゅ〜！」
*(10秒間、実演を促す静かな待ち時間。急かさない)*
**たねちゃん**: 「できたかな？できたひとは、にっこりして、みせてね！」

### [3:20-3:50] ふりかえり
**たねちゃん**: 「じょうずにできたね！はみがき、ぜんぶできたひとは、はなまる100こ！つぎも、いっしょにやろうね。」
*(ポーズ: [tanechan-banzai.jpg](../assets/characters/poses/tanechan-banzai.jpg) 万歳のよろこびポーズを使用)*
*(否定的な表現は一切使わない。できなかった子への配慮として「れんしゅうちゅうのひとも、はなまるだよ」と補足)*

### [3:50-4:00] ED
**たねちゃん**: 「またあおうね！チャンネルとうろく、まっててね！バイバイ！」
*(ED共通アニメーション+次回予告サムネ表示)*

## 演出・安全ガイドライン適用メモ

- カット割りは1カット3秒以上を基本とし、高速点滅・急なズーム・不規則なキャラクターの動きは使用しない
- BGM音量は会話より一段低く固定、効果音の急激な音量変化を避ける
- テロップはひらがな中心・大きめフォント、読み上げと同期
- 待ち時間(実践コーナー)を必ず設け、子供のペースを尊重する
- 作画は「たねちゃん」の確定デザイン([docs/character-design.md](../docs/character-design.md))に準拠し、表情変化を分かりやすく・動きは予測可能なものにする。この台本で使うポーズの対応は[character-design.md §6 台本対応表](../docs/character-design.md#台本対応表)を参照
