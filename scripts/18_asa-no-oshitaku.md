# 台本No.18: あさのおしたく、じぶんでできるよ

- **シリーズ**: せいかつしゅうかん
- **形式**: 長尺 / 尺目安 5分
- **対象年齢**: 3〜6歳
- **発達的ねらい**: 朝の身支度(着替え・歯磨き・持ち物準備)の一連の流れを見通し、自分の力で最後まで取り組む達成感を育てる。
- **監修ポイント**: これまでのシリーズ(はみがき・おきがえ)で身につけた個別スキルを、朝の生活動線としてつなげて見せる「総集編」的な位置づけにする。

## 概要欄(投稿時にそのまま使用)

```
【3歳〜6歳向け】保育士が教える、あさのおしたくが自分でできるようになる動画です。
この動画のねらい:朝の身支度の流れを見通し、自分の力で最後まで取り組む達成感を育てます。
はみがき・おきがえシリーズと合わせて見ると、さらに効果的です。

```

## 台本本編

### [0:00-0:08] OP
(ブランドジングル。「たねちゃん」登場)

### [0:08-0:25] 導入
**たねちゃん**: 「こんにちは！たねちゃんです。きょうは『あさのおしたく』を、じぶんで さいごまで やってみよう。」
*(ポーズ: [tanechan-wave.jpg](../assets/characters/poses/tanechan-wave.jpg))*
*(テロップ: 「あさのじゅんばん①おきる②おきがえ③はみがき④もちもの」を提示)*

### [0:25-3:40] 本編
**たねちゃん**: 「まず、あさ おきたら、カーテンあけて『おはよう』。」
*(テロップ「①おきる」ハイライト)*

**たねちゃん**: 「つぎは おきがえ。したぎ、うえのふく、ズボンの じゅんばんだったね。」
*(テロップ「②おきがえ」ハイライト、既存シリーズの手順を簡潔に振り返る)*

**たねちゃん**: 「それから はみがき。しゅっしゅっしゅ〜。」
*(ポーズ: [tanechan-toothbrush.jpg](../assets/characters/poses/tanechan-toothbrush.jpg))*
*(テロップ「③はみがき」ハイライト)*

**たねちゃん**: 「さいごに、もちものを かくにん。ハンカチ、あるかな？」
*(テロップ「④もちもの」ハイライト)*

**たねちゃん**: 「これで、あさのおしたく ぜんぶ できたね！」

### [3:40-4:30] 実践コーナー(視聴者参加)
**たねちゃん**: 「じゃあ、あしたの あさ、いっしょに やってみよう！おきる、おきがえ、はみがき、もちもの。じゅんばん おぼえられたかな？」
*(10秒間、振り返りを促す静かな間)*

### [4:30-5:00] ふりかえり+ED
**たねちゃん**: 「じぶんで さいごまで できたら、とっても すてきなことだよ。はなまる！」
*(ポーズ: [tanechan-banzai.jpg](../assets/characters/poses/tanechan-banzai.jpg))*
「またいっしょに がんばろうね。バイバイ！」

## 演出・安全ガイドライン適用メモ

- 既存シリーズ([02_hamigaki-lesson](./02_hamigaki-lesson.md)、[08_okigae-senshuken](./08_okigae-senshuken.md))と手順・テロップの表現を統一し、シリーズ間の一貫性を保つ
- 一連の流れが長いため、各ステップの間に短い区切り(効果音・テロップ切り替え)を入れて見通しを保つ
- カット割り・音量ルールは全シリーズ共通(1カット3秒以上、急な音量変化を避ける)
- 使用ポーズの一覧は[character-design.md §6 台本対応表](../docs/character-design.md#台本対応表)を参照
