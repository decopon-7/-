# 台本No.10: 「イヤイヤ期」との向き合い方(保護者向けショート)

> **ステータス: 保留(2026-09-18)** — 立ち上げ初期は「たねちゃん」の子供向け5シリーズに集中するため、みどり先生が登場する本シリーズは制作を一時保留している。台本自体は完成済みのため、フェーズ2再開時にそのまま使用する([channel-strategy.md](../docs/channel-strategy.md) §4参照)。

- **シリーズ**: ほいくしのワンポイント
- **形式**: ショート / 尺目安 60秒
- **対象**: 保護者向け(子供の視聴も妨げない穏やかなトーン)
- **狙い**: 保護者の育児不安を軽減し、専門性への信頼を獲得する。SNSシェアされやすい「明日から使える1つのコツ」形式にする。
- **監修ポイント**: 断定的な「正解」を押し付けず、保育現場での実践例として提示する。共感→具体策→まとめの3段構成。
- **出演形式**: 実写の顔出しは行わない。案内役はアニメキャラクター「みどり先生」([docs/character-design.md](../docs/character-design.md)参照)とし、声は監修者本人(保育士)が担当。肩書きテロップを画面に表示することで、匿名の一般論ではなく現場経験に基づく発信であることを伝える。

## 概要欄

```
【保護者向け】保育士が教える、イヤイヤ期の向き合い方のコツを60秒でお伝えします。
この動画のねらい:保護者の育児不安を少しでも軽くし、明日から使える関わり方のヒントをお届けします。

▼ほいくしのワンポイントシリーズ再生リストはこちら
（リンク挿入）

#イヤイヤ期 #育児 #保育士のアドバイス #子育てのヒント #発達支援
```

## 演出メモ

- 「みどり先生」の肩書きテロップ(声の出演者=監修者本人)を毎回統一フォーマットで表示し、E-E-A-T(専門性・信頼性)を積み上げる
- 断定表現(「〜すべき」「〜が正解」)を避け、「現場ではこうしています」という提案ベースの語り口にする
- 最後は必ず「完璧でなくてよい」という保護者を追い詰めないメッセージで締める
- 表情・動きは「きもちのじかん」シリーズ同様、落ち着いたトーンで統一し、急な動きは避ける
- 使用ポーズの一覧は[character-design.md §6 台本対応表](../docs/character-design.md#台本対応表)を参照
