# 台本No.3: おててをたたきましょう手遊び歌(ショート)

- **シリーズ**: ことばとうた
- **形式**: ショート / 尺目安 30秒
- **対象年齢**: 0〜2歳
- **発達的ねらい**: 大人の動きを真似ることで模倣力を育て、手指を動かすことで巧緻性・リズム感を養う。保護者との触れ合い遊びを促す。
- **監修ポイント**: 0〜2歳は保護者と一緒に見る前提のため、「おうちのひとと」というワードを必ず入れ、保護者が参加したくなる導線を作る。

## 概要欄

```
【0〜2歳向け】おうちのひとと一緒に遊べる手遊び歌です。
この動画のねらい:まねっこ遊びで模倣力を、手を動かすことで指先の発達を育てます。
続きの手遊びシリーズは本編でも配信中！

#手遊び歌 #0歳児 #1歳児 #2歳児 #知育あそび #保育士監修
```

## 演出メモ

- 30秒という短さでも急かす演出はせず、1テンポずつはっきり見せる
- 固定アングル・一定のBGM音量を保ち、感覚過敏の子にも配慮
- 終了カードで長尺本編(ことばとうたシリーズ)へ誘導し、回遊性を確保
- 使用ポーズの一覧は[character-design.md §6 台本対応表](../docs/character-design.md#台本対応表)を参照
